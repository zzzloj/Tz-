# Тестовый запуск на Railway

Это **подготовка окружения**, а не подтверждение работоспособности всех игровых сценариев. Архив содержит PHP-код 2004–2007 годов и зависимость от старых адресов других серверов. Публичный адрес можно включать только после настройки Basic Auth и проверки первых страниц.

1. Создать в Railway приватный сервис `mariadb:10.11` с томом `/var/lib/mysql` и базой `game`. Стандартный шаблон Railway использует MySQL 9.4, с которым старый `mysql_*` несовместим.
2. Подключить репозиторий `zzzloj/Tz-` как веб-сервис, выбрать Dockerfile `railway-preview/Dockerfile`, build context — корень репозитория.
3. Передать сервису переменные `MYSQLHOST`, `MYSQLPORT`, `MYSQLUSER`, `MYSQLPASSWORD`, `MYSQLDATABASE` из MariaDB, а также отдельные `PREVIEW_USER`, `PREVIEW_PASSWORD`. Пароли не добавлять в репозиторий.
4. Добавить веб-сервису постоянный том с точкой монтирования `/data`. Он хранит игровой мир и файлы состояния между перезапусками.
5. Проверить логи запуска, затем открыть `/1/g.php` под Basic Auth. По умолчанию публичный домен не создаётся.

Изолированный стартовый тест включает сервер 1 и таблицу `users`; форум специально заблокирован, потому что полного дампа форума нет. Оригинальная регистрация и переход между серверами используют устаревшие URL и потребуют отдельной правки после первого запуска. Современный браузер может не отображать WML как страницу игры.
