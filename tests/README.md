# Регрессионные тесты

`tests/run.sh` запускает всё подряд. Тот же скрипт выполняет GitHub Actions
(`.github/workflows/ci.yml`) на каждый push в `main` и на каждый pull request.

| Шаг | Что проверяет |
|---|---|
| `lint.sh` | `php -l` для всех PHP-файлов игры в том виде, как их собирает образ (кроме форума) |
| `content.sh` | `content/` собирается в файлы движка, и выгрузка собранного даёт тот же JSON |
| `scenario.py` | Сквозной сценарий игрока в Chromium: регистрация, вход, меню, диалог NPC, надеть нож, чат с «ё», карта, сохранение, админка `zx=mda`, смена пароля. Пароль не должен попадать в URL. |
| `crawl.py` | Три игрока параллельно случайно ходят по ссылкам. Падает на PHP Fatal, HTTP 5xx и ошибках JS. Кривой WML из оригинала выводится как `NOTE` и не валит прогон. |
| `integrity.php` | После обхода все записанные файлы мира (`l_i/`, `game.dat`, `online/`) читаются через `unserialize`, временных `.tmp.` не осталось. |
| `ab_walk.py` | Дифференциальный тест: две копии игры — предыдущий коммит и текущий — получают одинаковые запросы, экраны сравниваются. |

## Дифференциальный тест

Обе копии работают под libfaketime с общими замороженными часами, которые
тест сдвигает на 2 с за шаг. Генератор случайных чисел засевается от
`LEGACY_RANDOM_SEED` и запроса (`legacy_srand()` в `game/lib/legacy.php`).
Поэтому при одинаковом коде экраны совпадают байт в байт, а любое различие
означает изменение поведения.

Если экраны изменились намеренно (правка текста, новая кнопка), добавьте
`[ab-accept]` в сообщение коммита. Различия будут выведены, но прогон не упадёт.
Локально то же самое делает `AB_ACCEPT=1`.

## Запуск локально

Нужны PHP 8.4 (mysqli, gd, iconv, mbstring), MariaDB/MySQL, Python 3 с
`playwright` (`python -m playwright install chromium`) и пакет `faketime`.

```sh
export MYSQLHOST=127.0.0.1 MYSQLPORT=3306 MYSQLUSER=root MYSQLPASSWORD=...
BASE_REF=HEAD~1 bash tests/run.sh      # без BASE_REF дифференциальный тест пропускается
```

Каждая копия игры (`tests/env/instance.sh`) получает свой каталог в
`$TEST_ROOT` (по умолчанию `/tmp/tz-tests`), свою базу `tz_test_<имя>` и
встроенный сервер PHP. Порты: 8101/8102 для основной копии, 8201/8202 и
8301/8302 для дифференциального теста. Если порт занят чужим процессом, запуск
остановится с ошибкой.

Параметры: `CRAWL_STEPS` (по умолчанию 150 шагов на игрока), `AB_STEPS` (400).
`AB_DEBUG=1` выводит список посещённых запросов.
