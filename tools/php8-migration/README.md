# Инструменты переноса на PHP 8

Скрипты, которыми код `game/` переведён с PHP 5 на PHP 8.4. Все работают на токенизаторе PHP (`token_get_all`), поэтому не задевают строки и комментарии, и идемпотентны (повторный запуск ничего не меняет). Запускать из `game/` на PHP 8 с `-d short_open_tag=On`, аргумент — файл со списком PHP-файлов (например, `grep -rlI '<?' . > list.txt`).

Порядок, в котором они применялись:
1. `fix_braces.php` — `$s{0}` → `$s[0]`.
2. `fix_preg_e.php` — `preg_replace(.../e)` → `preg_replace_callback` с замыканием.
3. ручные правки: `$HTTP_*_VARS`, `ereg*`, `split`, `each`, `session_register`, `convert_cyr_string`, голые константы, `parse_str($x)` (см. историю коммитов).
4. `fix_open_tags.php` — `<?` → `<?php`.
5. `fix_count.php` — `count(X)` → `count((array)(X))`.
6. `fix_array_args.php` — `(array)` для аргументов `implode`/`in_array`/`array_*` (запускать до неподвижной точки).
7. `fix_numeric.php` — `legacy_num()`/`legacy_cmp()` вокруг операндов арифметики и сравнений с числами (см. `game/lib/legacy.php`).
8. `fix_fileops.php` — `fread`/`fclose`/... → `legacy_f*()`.
9. `evalcode.php extract|apply` — то же для PHP-кода внутри данных (`"eval: ..."` в диалогах, `f_attackf.dat`): извлекает фрагменты во временные файлы, по ним прогоняются шаги 1–8, затем фрагменты возвращаются на место.

Диагностика: `scan.php` (удалённые функции, `/e`, голые константы, `mysql_*`), `calls.php` (вызовы с `/e`), `count_ops.php`, `concat_prec.php` (выражения `A . B + C`, чей смысл изменился в PHP 8).

`ab_walk.py` — сравнение с эталоном: одна и та же последовательность запросов к копии на PHP 5.6 (старый код) и на PHP 8.4 (новый код) с одинаковым снимком мира; сравнивает сырой WML после нормализации времени и случайных параметров.
