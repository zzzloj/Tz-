# Тестовый запуск на Railway

Тестовое окружение запущено в проекте Railway `territory-evil-legacy-preview`. Стартовый экран сервера 1 отвечает по адресу https://territory-evil-php-production.up.railway.app/1/g.php: без Basic Auth возвращается HTTP 401, с настроенными `PREVIEW_USER` и `PREVIEW_PASSWORD` — HTTP 200 и HTML. Игра отдаёт WML; `html-output.php` заворачивает исходную колоду в HTML-оболочку, а `wml.js` отрисовывает её как WAP-браузер (карточки, переменные `$(var)`/`<setvar>`, `<go>`/`<prev/>`, меню `<do>`, таймеры, картинки); код игры в `game/` перенесён на PHP 8.4 (см. корневой README); `fix-game.py` при сборке накладывает только заплатки, специфичные для этого окружения (внутренний запрос входа, `sql_mode`, форма возраста, ссылки на старые домены). Образ — `php:8.4-apache` с `mysqli` и GD.

1. Создать в Railway приватный сервис `mariadb:10.11` с томом `/var/lib/mysql` и базой `game`. Стандартный шаблон Railway использует MySQL 9.4; таблицы игры рассчитаны на MariaDB/MySQL 5 (`MyISAM`, `cp1251`).
2. Подключить репозиторий `zzzloj/Tz-` (ветка `main`) как веб-сервис, выбрать Dockerfile `railway-preview/Dockerfile`, build context — корень репозитория.
3. Передать сервису переменные `MYSQLHOST`, `MYSQLPORT`, `MYSQLUSER`, `MYSQLPASSWORD`, `MYSQLDATABASE` из MariaDB, а также отдельные `PREVIEW_USER`, `PREVIEW_PASSWORD`. Пароли не добавлять в репозиторий.
4. Добавить веб-сервису постоянный том с точкой монтирования `/data`. Он хранит игровой мир и файлы состояния между перезапусками.
5. Проверить логи запуска, затем открыть `/1/g.php` под Basic Auth. Действующий домен указан выше; пароль хранится только в приватных переменных Railway.

Изолированный стартовый тест включает сервер 1 и таблицу `users`; форум специально заблокирован, потому что полного дампа форума нет. `wml.js` пропускает только внутренние ссылки и хранит переменные WML в `sessionStorage` вкладки. Ссылки на старые домены игры переписываются на локальные при сборке (`fix-game.py`), форум и SMS показываются неактивными. Код игры обновляется на томе при каждом старте (`sync-code.sh`), состояние мира сохраняется. Переход между серверами (сервер 2) не настроен. Исходные WML-страницы не переписаны в HTML.
