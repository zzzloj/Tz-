# Боевая механика «Территории Зла»

Описание боя в том виде, в каком он реализован в движке `game/1`. Каждое правило снабжено ссылкой `файл:строка`; номера строк считаются после `iconv -f cp1251 -t utf-8`, как и в `docs/data-fields.md`. Имена полей (`war[0]` = `hit_chance`, `char[6]` = `busy_until`, `skills[9]` = `cold_weapon` и т.д.) взяты из `docs/data-fields.md` §3; здесь они не расшифровываются повторно. Квесты описаны в `docs/quests.md`.

Условности:

* `rand(a,b)` в PHP включает обе границы. Поэтому проверка `rand(0,100)<=X` срабатывает с вероятностью `(X+1)/101`, а `rand(0,100)>X` с вероятностью `(100-X)/101`. Ниже для краткости вместо этого пишется «X %».
* Везде, где сказано «игрок», имеется в виду сущность `u.*`, «NPC» означает `n.*`.
* Пометка **(не проверено)** стоит там, где вывод сделан только по чтению кода, без запуска.

## 1. Боевые параметры игрока (`f_calcparam.dat`)

`calcparam()` строит `war` игрока с нуля: массив из 18 нулей (`f_calcparam.dat:14`). Из старого `war` переносятся только `[15]` и `[16]` (записи о PvP-убийствах, `f_calcparam.dat:130`). Для `u.qv`, `u.qw`, `u.kv`, `u.scream` пересчёт не делается (`g.php:678`).

Вызывается при надевании и снятии вещи (`plugin/i.w.dat:34`), при потере надетого предмета (`f_additem.dat:80`), при смерти (`f_kill.dat:63`), при получении очка опыта (`f_kill.dat:111`, `f_addexp.dat:12`), при повышении навыка (`f_speakskillup.dat:142`), при регистрации (`f_site_reg2.dat:33`), при сбивании с коня (`plugin/m.kon.dat:24`) и в `m.armor` (§5.5). **На каждом ударе `calcparam()` не вызывается**: в бою используется закэшированный `war`, поэтому баффы через `war` живут до следующего пересчёта.

Обозначения навыков: `str=skills[0]`, `dex=skills[1]`, `int=skills[2]`, `hand=skills[8]`, `cw=skills[9]`, `rng=skills[10]`, `parr=skills[11]`, `dodge=skills[12]`, `mres=skills[14]`, `mdodge=skills[15]`.

### 1.1 Характеристики персонажа

```
hp_max   char[2] = 10 + str*10            (+10 держателю флага в этой локации)   f_calcparam.dat:10-11
mana_max char[4] = 10 + int*10                                                   f_calcparam.dat:12
```
Сюда же добавляются самоцветы с индексом `>50` (§1.6). Текущие HP и мана обрезаются сверху по максимуму (`f_calcparam.dat:125-126`).

### 1.2 Защита (не зависит от экипировки)

```
war[6]  dodge        = dex + dodge + (str-1)*2                  f_calcparam.dat:15
war[7]  parry        = 2*(dex + parr + (str-1)*2)               f_calcparam.dat:16
war[9]  magic_dodge  = 5*(int + mdodge - str)                   f_calcparam.dat:17
war[10] magic_parry  = 10*(int + mres - str)                    f_calcparam.dat:18
war[11] magic_resist = 15*(mres + int - str)                    f_calcparam.dat:19
war[13] exp_value    = сумма всех skills, кроме skills[3]        f_calcparam.dat:21
```
* Сила **увеличивает** физический уклон и парирование и **уменьшает** все три магические защиты.
* `war[13]` включает `skills[4]` (неизрасходованные очки опыта). Поэтому трата очка на навык сумму не меняет.
* Без щита (`i.a.s.*` в `equip`) парирование обнуляется (`f_calcparam.dat:124`).

### 1.3 Экипировка: общий цикл

Для каждого id в `equip` (`f_calcparam.dat:29-88`):

1. Если предмета нет в `items` или нет файла определения, он снимается (`f_calcparam.dat:32`).
2. Требования `str:dex:int` берутся у брони из поля `[3]`, у оружия из `[4]` (`f_calcparam.dat:35-38`). Считается нехватка каждого атрибута: `dexdef`, `intdef`, `strdef` (`f_calcparam.dat:40-42`).
3. **Штраф меткости**: `hits += dexdef*10` для любой надетой вещи, включая броню (`f_calcparam.dat:43`). Вся сумма вычитается из `war[0]` в конце (`f_calcparam.dat:111`).
4. **Броня** (не щит): `war[5] += max(0, armor - 2*strdef - 2*intdef)` (`f_calcparam.dat:45`). Отрицательный вклад отдельной вещи отбрасывается.
5. **Щит** `i.a.s.*`: `war[8] = armor - 2*strdef - 2*intdef`, если значение > 0 (`f_calcparam.dat:46`). Броня щита **не** входит в `war[5]`. Она работает только при парировании (§2.6).

### 1.4 Оружие `i.w.*` (`f_calcparam.dat:48-72`)

```
war[3] attack_delay = speed - round(dex/2)                      :50   (round(0.5)=1, round(1.5)=2 ...)
war[4] is_ranged    = 1 для i.w.r.*                             :51
war[12] verb        = поле verb оружия                          :52
war[14] ammo        = поле ammo оружия (и у холодного тоже)     :54,58

war[0] hit:
  стрелковое i.w.r.*: += 10*(dex + rng - 1);  -10 верхом (char[12])   :55-56
  прочее:             += 10*(dex + cw)                               :59

war[1..2] урон:
  посох (verb == 'магией'):  min += dmg_min - 2*strdef - 4*intdef
                             max += dmg_max - 2*strdef - 5*intdef     :61-63
  прочее:                    min/max += dmg - 2*strdef - 2*intdef     :65-66
  заточка «-N-» в id:        min/max += min(N,6)                      :69-70
  все, кроме арбалетов i.w.r.c.*: min/max += str                      :71
```
Навык владения оружием (`cw`, `rng`) влияет **только на меткость**. На урон он не влияет. Сила прибавляется к урону любого оружия, в том числе луков, метательного и посохов. Не получают её только арбалеты.

Классы оружия по префиксу id (в данных: `i.w.k.` 19 шт., `i.w.r.` 40, `i.w.s.` 24, `i.w.u.` 17, `i.w.t.` 6, `i.w.spear.` 2):

| Префикс | Особенность в бою |
|---|---|
| `i.w.r.` | стрелковое или метательное: меткость от `rng`, крит 5 %, штраф стрельбы верхом, не совместимо со щитом (`plugin/i.w.dat:21,29`), приёмы запрещены (`f_usepriem.dat:6`). Расходует `ammo`. У метательного (`i.w.r.knife`, `drotik`, `stone`…) `ammo` указывает на сам предмет, поэтому оружие тратится при броске и после последнего снимается. |
| `i.w.r.c.` | арбалеты: без бонуса силы к урону |
| `i.w.u.*`, `i.w.s.jezl` (`verb` = `магией`) | посохи: усиленный штраф за нехватку int, атака идёт по магической ветке (§2.4) |
| `i.w.k.` | нож; применённый к трупу, разделывает его (`plugin/i.w.dat:4-5`) |
| `i.w.t.` | топор; применённый к дереву, рубит его (`plugin/i.w.dat:7-8`) |

### 1.5 Без оружия (`f_calcparam.dat:91-99`)

```
war[1] = str + hand - 1
war[2] = str + hand + 1
war[0] += 10*(dex + hand + 2);  если >=100, то 95;  -20 верхом
war[3] = 5 - round(dex/2)
war[12] = 'кулаками'
```

### 1.6 Самоцветы (`f_calcparam.dat:74-87`)

Для вещей, id которых содержит `_`, `-` или `..`, из id извлекаются все `..<код>`. Эффекты `items/i.i.<код>` (поле `effects`, формат описан в data-fields §1.4) прибавляются: при индексе `<50` к `war[idx]`, при индексе `>50` к `char[idx-50]`. Самоцвет одного вида учитывается только один раз на весь комплект (строка `$art`).

Жёстко заданные в коде эффекты самоцветов:
* `..do` в любом месте экипировки даёт ещё `-20` к меткости (`f_calcparam.dat:110`).
* `..kp` даёт `+4` к шансу крита (`f_attackf.dat:99`).
* `..gt` даёт `+10` к шансу некромантии (`f_necro.dat:26`).
* `..am`, `..ne`, `..on`, `..ma` пересчитываются в заклинаниях `m.str` и `m.man` (`plugin/m.str.dat:10-12`, `plugin/m.man.dat:9-10`).

Поля `war[3]` и `war[12]` оружие **присваивает**, а не прибавляет. Поэтому эффект самоцвета на `war[3]` (например, `i.i.az`, «отдых -3 сек») пропадает, если вещь с камнем стоит в `equip` раньше оружия, и всегда пропадает без оружия (`f_calcparam.dat:97` выполняется после цикла). Та же судьба у `i.i.gt` (`3:+10`): его штраф к паузе тоже может исчезнуть.

### 1.7 Комплекты (`f_calcparam.dat:100-102`)

| Комплект | Условие (подстроки в `equip`) | Бонус |
|---|---|---|
| адамантовый | `i.a.h.ms`, `i.a.b.sborn`, `i.a.p.ms`, `i.a.l.ms`, `i.w.s.master` | HP +5, мана +5, меткость +5, броня +5, урон +4/+3 (min/max) |
| огр/тролль | `i.a.l.ogr`, `i.a.p.ogr`, `i.a.b.troll` и `i.a.h.whitewolf` или `i.a.h.wolf` | HP +5, мана +5, броня +4 |

Особый предмет: `i.a.m.vlast` (амулет тёмной власти) удваивает min и max урона по целям `n.c.*` (`f_attackf.dat:73-74`).

### 1.8 Итоговые ограничения (`f_calcparam.dat:114-124`)

```
war[0]: <=0 → 5 (значения 1..4 остаются как есть); >95 → 95
war[1], war[2], war[5], war[6], war[7], war[9], war[10]: <0 → 0
war[3]: <3 → 3
war[7] = 0, если нет щита
```
`war[8]` и `war[11]` снизу не ограничены. Отрицательный `war[11]` безвреден, потому что при нём и `war[10]` отрицателен и обнуляется.

### 1.9 Прочие модификаторы вне `calcparam`

* Держатель флага лидерства получает `+10 hp_max` (`f_calcparam.dat:11`), `+10` к меткости приёмов (`f_usepriem.dat:24`) и `+20` к шансу каста (`f_usemagic.dat:26`), но сам считается законной целью (§3.1).
* Всадник (`char[12]`) получает `-10` к меткости стрелкового оружия и `-20` без оружия (`f_calcparam.dat:56,96`), `-10` к касту (`f_usemagic.dat:25`), ещё `-10` к приёмам (`f_usepriem.dat:26`). По нему самому бьют с `-10` к меткости (`f_attackf.dat:72`). С холодным оружием штрафа нет.

## 2. Атака шаг за шагом (`f_attackf.dat`)

Сигнатура: `attack($loc,$from,$to,$magic='',$answer=1,$rmagic=0,$priem='',$ptitle_v='')` (`g.php:609`).

* `$magic` задаёт готовую строку `war`, которая подменяет `war` атакующего (так работают приёмы, заклинания, бутылки).
* `$answer=1` означает «инициативную» атаку: ставит паузу атакующему и вызывает ответный удар. `$answer=0` означает ответный удар, заклинание или бросок.
* `$rmagic=1` означает магическую атаку заклинанием или предметом.

Кто вызывает `attack()`:

| Источник | Вызов |
|---|---|
| игрок: `ca=<id>` | `attack($loc,$login,$ca)` (`g.php:180`), перед этим `char[7]=$ca` |
| NPC в `doai()` | `attack($i,$j,$char[7])` (`g.php:604`) |
| ответный удар | `attack($loct,$to,$from,0,0)` (`f_attackf.dat:171`) |
| приём | `attack(...,$magic,1,0,$use,$priem[0])` (`f_usepriem.dat:51,53,54`) |
| боевое заклинание | `attack(...,$war,0,1)` (`plugin/m.w.dat:21-22`) |
| бутылки и квестовые предметы | `plugin/i.b.fire.dat:14`, `i.b.jad.dat:14`, `i.b.jad.c.dat:20`, `i.b.holy.dat:15`, `i.q.pdeath.dat:15` (все с `rmagic=1`), `i.q.ssword.dat:13` (обычная) |
| сбить с коня, безумие, натравить питомца | `plugin/m.kon.dat:15`, `plugin/m.maddnes.dat:17`; питомцу через `f_speakowner.dat:69-81` ставится `char[7]`, дальше работает `doai` |

Если в запросе передан `attackf` (например, `?attackf=1`), `attack()` не делает ничего: `global $attackf; if (!$attackf) eval(...)` (`g.php:610-612`), а `g.php:3-6` делает `extract($_GET)`. См. §9.

### 2.1 Кто может атаковать кого

По порядку проверок:

1. Обе стороны должны быть `u.*` или `n.*`, находиться в одной локации и не совпадать (`f_attackf.dat:4`).
2. Игрок-призрак атаковать не может (`f_attackf.dat:6`; у ручной атаки есть и сообщение в `f_attack.dat:3`, но этот файл мёртвый). Призрака атаковать нельзя (`f_attackf.dat:11`).
3. В банке `x1092x474` атака запрещена, если ни атакующий, ни цель не преступники. Исключение: `u.admin`, `u.sn0k` (`f_attackf.dat:13-15`).
4. Пауза: если `char[6]` атакующего стоит больше чем на 300 с в будущем, он сбрасывается (`:17`). Если `time() <= char[6]` и атака не магическая, атака отменяется: «Вы должны отдохнуть N сек» (`:18-21`). Сообщение выводится только при `$answer`. **Заклинания и бутылки (`$rmagic`) паузу здесь не проверяют.** Её проверяет `g.php:187` до использования любого `use=`.
5. Если `$answer`, атакующему сразу ставится `char[6] = time() + war[3]` (`:27`). Пауза тратится, даже если дальше атака сорвётся (нет боеприпасов и т.п.).

Зон «мирных» для боя, кроме банка, нет. Охраняемая зона (`zone=1`) только вызывает стражу (§6.4). Режим бога: цель с ключом `god` получает урон 0 (`f_attackf.dat:101`) и не видна в списке объектов (`g.php:249`), но атаковать её формально можно.

### 2.2 Выбор ветки: физика или магия (`f_attackf.dat:30-40`)

Атака магическая, если `$rmagic` или `verb ∈ {магией, молнией}` (`:30`). Тогда защитой служат `magic_dodge=war[9]`, `magic_parry=war[10]`, `magic_resist=war[11]` цели (`:34`). Иначе защитой служат `dodge=war[6]`, `parry=war[7]`, `shield_armor=war[8]` (`:36`).

Тут же применяются защитные стойки цели (`def`, §4.2): `p.d.z`/`p.d.c` в магической ветке (`:31-33`), `p.d.u`/`p.d.re`/`p.d.p` в физической (`:37-39`), `p.d.g` против `p.g` (`:42`), `p.d.o` против всего, кроме `$rmagic` (`:44`). Своя стойка атакующего `p.d.re` режет его урон до 60 % (`:43`).

### 2.3 Преступление (`f_attackf.dat:50-63`)

Проверяется **до** броска на попадание: одна попытка удара уже делает преступником.

```
fcrim = char[9] атакующего || from начинается с n.c.                                     :54
tcrim = char[9] цели || to = n.c.* || to ∈ {n.w.Veelzevul, n.whitewolf}
        || цель держит флаг в этой локации                                                :56
на Волчьем острове (Y >= 1099) также: цель пират (char[14]=p) || to = n.p.*
        || атакующий пират, а цель тамплиер                                               :57
```
`docrim` вызывается, если одновременно (`:59`):
* атакующий не преступник, цель не преступник;
* цель сейчас не атакует атакующего (`tchar[7] != from`; это самооборона);
* они не из одного клана (клан берётся из имени `Имя *Клан*`, `:50-53`) и не супруги (`:58`);
* ни одна из сторон не входит в служебные логины `u.qv`, `u.admin`, `u.qw`, `u.kv`, `u.scream`.

Что получает атакующий: у цели есть ключ `owner` (питомец, наёмник, призванный, лошадь, стража замка) → титул «живодер» (`:60`). Иначе, если цель не `n.a.*`, → «бандит» (`:61`). **Нападение на ничьё животное `n.a.*` не преступление нигде**: условие для города закомментировано в той же строке. Нападение на торговца, стражника `n.g.*` или сюжетного NPC даёт «бандит». `docrim` действует только на игроков (`f_docrim.dat:6`), поэтому NPC преступниками через атаку не становятся.

Уже действующий преступник повторно не помечается, и срок его статуса при атаке **не продлевается**. Продлевает только убийство (§6.2).

### 2.4 Боеприпасы, всадник, амулет власти

* Если `war[14]` задан, в `items` должен быть этот id, иначе «Нет боеприпасов» и выход (`f_attackf.dat:66-70`). Один заряд списывается **до** броска на попадание. Списывается и при ответном ударе. Когда заряды кончаются, выводится «Боеприпасы кончились».
* Цель-игрок верхом: меткость `-10`, кроме `$rmagic` и `магией` (`:72`). На `молнией` штраф действует.
* `i.a.m.vlast` на атакующем удваивает урон по `n.c.*` (`:73-74`).

### 2.5 Бросок на попадание и урон

```
если war[0]==0 и атака магическая → весь блок пропускается: ни урона, ни журнала,
   ни ответного удара («заклинание сорвалось»)                                  :77
попадание:  rand(0,100) <= war[0]                                             :79
урон:       damage = rand(war[1], war[2])                                      :81
в замке c.1..c.5, если клан атакующего владеет замком: damage += rand(0,10)   :83-87
«время суток»: damage -= rand(0,5)        (задумано как ±, см. §9)            :88-89
```

### 2.6 Уклон, щит, сопротивление магии, броня, крит

Выполняется только при попадании:

```
уклон: rand(0,100) > dodge     иначе промах «мимо (уклон)» / «(уклон от магии)» :92
щит/сопротивление, если parry>0 и shield>0, при rand(0,100) <= parry:           :94
    физика: damage -= shield_armor                  журнал «(щит N)»
    магия:  resist = round(damage*magic_resist/100); damage -= rand(0,resist)
                                                    журнал «(сопр. магии N)»
броня (только физика, не $rmagic/магией/молнией): damage -= rand(0, armor)     :96
damage = max(0, damage)                                                          :97
крит: шанс 5 (стрелковое, war[4]) / 4 (магия) / 2 (прочее), +4 с ..kp;
      при damage>0 и rand(0,100) < шанс → damage*=2, журнал «критически»        :98-100
god: damage = 0                                                                  :101
char[1] -= damage (не ниже 0); char[5] = time()                                 :103-105
```
* `char[5]=time()` (метка регенерации) пишется при любом прошедшем уклон попадании, даже с уроном 0. Такое попадание сбрасывает отсчёт регенерации цели (§7.1).
* Щит у игрока работает только при надетом `i.a.s.*`. У NPC работает, если в шаблоне заданы `war[7]` и `war[8]`.

### 2.7 Журнал (`f_attackf.dat:106-113`, `137-164`)

* Инициативная атака (`$answer=1`, не магия): атакующему «Вы по <цель>[ критически] <verb> N[ (щит N)][ (стойка)]», цели «<атакующий> по вам …», остальным «<атакующий> по <цель> …».
* Ответный удар, заклинание, бросок (`$answer=0` или `$rmagic`): короткая форма «вы <verb> N» дописывается через `", "` к последней строке журнала атакующего. Всем, кроме атакующего, пишется «<имя> <verb> N». **Имя цели в короткой форме не выводится.**
* Промахи: «мимо» (не попал), «мимо (уклон)», «мимо (уклон от магии)».
* `$ptitle_v` (название приёма) выводится в скобках после имени. `$t2` показывает название сработавшей стойки цели.
* Если ранен игрок-супруг, второму супругу в другой локации приходит ссылка «Ваша жена/муж ранен(а)!». Не чаще раза в 300 с (`:116-131`).

### 2.8 Смерть и продолжение боя

* Если `char[1] < 1`, подключается `f_kill.dat` (`:133-135`, §6). Проверка стоит только в ветке попадания. Цель с 0 HP (например, только что воскрешённая, §6.3) погибает от любого удара, прошедшего уклон, даже при уроне 0.
* Атакующий запоминает цель `char[7]=$to` при `$answer` или `$rmagic` (`:168`).
* Если атака не была «сорвавшимся» заклинанием (`:169`):
  * NPC-цель переключает `char[7]` на атакующего (`:170`). По замыслу только если она свободна, но из-за опечатки `$tсhar` (кириллическая «с») условие всегда истинно: **NPC всегда переключается на последнего ударившего**.
  * при `$answer=1` цель **немедленно отвечает ударом** `attack($to,$from,0,0)` (`:171`). Ответ проходит через ту же проверку паузы (`:18`), но сам паузу не ставит (`:27` только при `$answer`). Цель, которая не отдыхает, получает бесплатный удар на каждый входящий инициативный удар. Это касается и игроков: игрок отвечает NPC и другим игрокам автоматически. На заклинания и броски (`$answer=0`) ответа нет.

### 2.9 Порядок на одном запросе игрока

`g.php` на каждом запросе сначала запускает `doai()` для текущей локации и всех соседних (`g.php:150-151`), а уже потом выполняет действие игрока (`ca=` в `g.php:180`, `use=` в `g.php:184-199`). Время боя дискретно: NPC «живут» только при запросах игроков, которые находятся в их локации или рядом. Если рядом никого нет, NPC стоят.

Во время боя можно уйти в соседнюю локацию: переход `go=` паузу не проверяет (`g.php:117-137`). NPC может последовать (§3.3).

## 3. ИИ NPC в бою (`g.php:530-607`, `doai()`)

### 3.1 Списки целей (`g.php:545-557`)

Для обрабатываемой локации строятся два списка (служебные логины исключаются):
* `$users`: живые игроки. Каждый попадает в список с вероятностью `rand(0,100) > hiding*6` (`skills[17]`, `g.php:552`). Потолок навыка 5 (`g_skills_one`, `g.php:47`), учителя учат до 4, так что на практике шанс не попасть в список на тике не больше ≈30 % (при 5) или ≈24 % (при 4).
* `$crim`: игроки с `char[9]` (кроме зоны 3), пираты в зоне 2 и тамплиеры в зоне 3 на острове, а также **все `n.c.*`** (`g.php:552,554`).

### 3.2 Обработка каждого NPC (`g.php:585-604`)

1. **Бегство** (`f_run.dat`): только в локации самого игрока, если NPC не отдыхает, `HP < hp_max/4` и `rand(0,100)<50`. Не бегут `n.s.*`, `n.o.*`, `n.z.*` (`g.php:586`). NPC уходит в случайный выход той же зоны и сбрасывает цель (`f_run.dat:4-12`). Если выпавший выход ведёт в другую зону, бегства в этот раз нет.
2. Цель-призрак сбрасывается (`g.php:587`).
3. Стражник `n.g.*` по истечении `char[11]` исчезает (`g.php:589`).
4. Подчинённые (`owner`) обрабатываются в `f_owner.dat` (§5.6).
5. **Погоня** (`f_goto.dat`): если цель ушла, NPC ищет её в соседних локациях и идёт следом, только если зона совпадает (стражник `n.g.` ходит в любую, `f_goto.dat:8`). Игрок уходит от погони с шансом `hiding*4 + dex` % (`f_goto.dat:12`). От стражи уйти нельзя (`:9-10`). Призраков не преследуют (`:15-22`). Если цель не нашлась, `char[7]` сбрасывается (`g.php:591-595`).
6. **Выбор новой цели**, если её нет (`g.php:596-599`):
   * `n.g.*`, `n.t.*`, `n.p.*` берут случайную цель из `$crim`. Стража охраняемой зоны поэтому бьёт и забредших монстров `n.c.*`.
   * `n.c.*` и NPC с `char[9]` (например, призванный демон) берут случайного игрока из `$users`. Монстры агрессивны **только к игрокам**; других NPC они сами не трогают.
   * Остальные (`n.a.*`, торговцы, сюжетные) пассивны, пока их не ударят (§2.8).
7. Стража замка `n.o.*` в замке атакует игроков не из клана-владельца и не из списка гостей ворот (`f_no.dat:4-14`).
8. Без цели NPC блуждает (`f_na.dat`).
9. При наличии цели: `attack($i,$j,$char[7])` с `$answer=1` (`g.php:604`), то есть с паузой `war[3]` и ответным ударом жертвы.

NPC бьют строго своим `war` из шаблона. Сила к урону не добавляется, `calcparam` для NPC не вызывается.

### 3.3 Приёмы и магия у NPC

**NPC приёмы не используют.** В `f_attackf.dat:29` NPC с вероятностью ≈90 % получает `$use="p.p"`, но переменная локальная и дальше не читается. Похоже на незаконченную подводку к `f_mobpriem.dat`, который нигде не подключён. В старом `f_attackf1.dat:26` NPC с шансом 7 % переключал `verb` на `магией`. Заклинаний NPC тоже не кастуют. «Магические» NPC — это шаблоны с `verb` = `магией`/`молнией` (например, `n.c.darkmage`, `n.c.ghost`, `n.c.demon`, призванные фантом и туча): их обычные удары идут по магической ветке (§2.2).

### 3.4 Усмирение

`m.peace` (цель) и `m.silence` (все NPC в локации) обнуляют `char[7]` (`plugin/m.peace.dat:5`, `plugin/m.silence.dat:5`). Агрессор `n.c.*` на следующем тике `doai` снова выберет цель из `$users` (`g.php:598`), так что против монстров эффект мгновенно пропадает.

## 4. Приёмы (`f_usepriem.dat`)

### 4.1 Общие правила

* Запрещены со стрелковым оружием (`f_usepriem.dat:6`). В банке запрещены всегда **(вероятно)**: проверка `:3` использует неопределённые здесь `$fchar/$tchar/$from`, поэтому условие «оба не преступники» истинно всегда (не проверено).
* Номер `p.1…p.9` берётся из книги `priem` (`:8-12`). Приём нужно знать (`:15`), к себе применять нельзя (`:16`).
* Атакующим приёмам нужна цель в локации и истёкший период `priem` (`:19-20`). После применения период ставится на `time()+cooldown` (`:30`).
* Меткость приёма (`:24-26,32`):

```
magic = war игрока
magic[0] = war[0] (+10 флаг) - (int-1)*10 (-10 верхом)
```
Интеллект **снижает** точность приёмов, так и написано в справке `desc/p`.
* Итог обрезается: `<1 → 5`, `>95 → 95`, урон `>=0` (`:46-49`). Затем `attack(... ,$magic, 1, 0, $use, имя)`, то есть с паузой `magic[3]` и ответным ударом цели.

## 5. Магия (`f_usemagic.dat`, `plugin/m.*.dat`)

### 5.1 Каст (`f_usemagic.dat`)

1. Номер `m.1…m.9` берётся из книги (`:4-8`). Без свитка заклинание должно быть в книге (`:11`).
2. Цель нужна, если `needs_target`. Для `m.w.a.*` нужен ещё кто-то в локации (`:14-15`). Если цели нет, выводится список (`:61`).
3. `char[3] >= mana_cost`, иначе «Недостаточно маны» (`:18`). Период из книги должен истечь. Свитки и руны период не проверяют (`:20`).
4. Шанс (`:24-32`):

```
cast = (magic*0.5 + int*1.5)*10 - level*10 + 10 - (max(str,2)-2)*4
       -10 верхом; +20 держателю флага; не больше 95
служебные u.qv, u.admin, u.qw, u.kv, u.scream: cast=100, str считается 1
```
5. Если `cast <= 0` или навык `magic` (`skills[13]`) равен 0, выводится «Слишком слабый навык магии». Мана не тратится (`:33,57`). **Это касается и свитков**: без навыка магии свиток не прочесть.
6. Мана списывается, ставится пауза (`:34-35`):

```
char[6] = time() + cast_time + 3 - dex + (max(str,2)-2)*4
```
   Снизу пауза не ограничена (минимальный `cast_time` в данных 4, dex до 5).
7. Период (`:38`): `cooldown`, для `m.w.*` плюс `(max(str,2)-2)*1200` с. Свиток при этом расходуется (`:40`), руна нет.
8. Слова заклинания пишутся в журнал всем (`:42-46`).
9. Успех при `rand(0,100) <= cast` (`:47`): `m.w.*` → `plugin/m.w.dat`, `m.heal*` → `plugin/m.heal.dat`, `m.s.*` → `plugin/m.s.dat`, остальные → `plugin/<id>.dat` (`:49-54`).
10. Провал: «Заклинание сорвалось». Мана, пауза и период уже потрачены. Для `m.w.*` всё равно вызывается `m.w.dat` с `$loss=1` (`:56`), и цель помечается преступлением (§5.2).

### 5.2 Боевые заклинания `m.w.*` (`plugin/m.w.dat`)

```
war[0] = 100 (при $loss = 0)
war[1] = max(0, power_min - 10 + int*2)
war[2] = power_max + int*2
war[3] = cast_time, war[4] = 0, war[12] = 'магией', war[14] = ''         m.w.dat:6
```
Далее `attack(..., $war, 0, 1)` по цели (`:22`) или, для `m.w.a.*`, по **каждому** `u./n.` в локации, кроме заклинателя (`:10-11`), включая своих питомцев и невиновных игроков.
* Магическая ветка: промах возможен только через `magic_dodge` цели, частичное гашение через `magic_parry/resist`. Броня не действует. Крит 4 %. `-rand(0,5)` к урону тоже применяется (§2.5).
* `criminals_only` (`m.w.holyarrow`, `m.w.a.godanger`, `m.w.a.qv`): атака только по преступникам и `n.c.*` (`:22`).
* `m.w.hit` до атаки отнимает у цели `rand(power_min, power_max)` маны, без проверки уклона (`:20`).
* `m.w.vamp` лечит заклинателя на `rand(2, power_min)` с ограничением по максимуму HP, **независимо от попадания** (`:25-31`). Условие `:21-22` устроено так, что атака проходит по любой цели, хотя в описании «не действует на преступников и монстров».
* При `$loss=1` у атаки `war[0]=0`: урона и ответа нет, но проверка преступления (§2.3) уже выполнена (`f_attackf.dat:59` стоит выше `:77`).

Урон с int 1 для примера: «Магическая стрела» (`4..10`, lvl 1) даёт `0..12`. Шанс каста при magic 1, int 1, str 1: `(0.5+1.5)*10 - 10 + 10 = 20` %.

### 5.3 Лечение (`plugin/m.heal.dat`)

```
heal = rand(max(0, power_min - 10 + int*2), power_max + int*2), не больше недостающего HP   :25-26
```
* `m.heal`, `m.heal.great` действуют на цель. `m.heal.all` лечит себя, соклановцев, своих подчинённых (`owner` начинается с логина) и, в своём замке, стражу `n.o.*` (`:9-19`).
* Лечение преступника или `n.c.*` делает невиновного заклинателя преступником «лечил преступника» (`:32`).
* Призрака лечение не воскрешает (проверки на призрака нет, HP у призрака просто растут).

### 5.6 Подчинённые в бою (`f_owner.dat`)

* Охрана: если кто-то атакует охраняемого (`owner[2]`) или его подопечных, подчинённый берёт атакующего целью. В охраняемой зоне преступника не защищают (`f_owner.dat:67-72`).
* Следование: не больше трёх подчинённых за одним хозяином в одну локацию (`:49`). Не следуют за призраком (`:46`).
* Натравить питомца (`f_speakowner.dat:69-81`): невиновный хозяин получает «преступник», если цель невиновна и не `n.a.*`, **или** если цель `n.a.*` в охраняемой зоне. В охраняемой зоне преступником становится и сам питомец. Это единственное место, где нападение на животное в городе преступно.
* Опыт за убийство NPC подчинённым (`n.s.`, `n.z.`, `n.a.`) получает `owner[1]` (за кем следует), половину от `war[13]` жертвы (`f_kill.dat:124-135`).

### 5.7 Некромантия (`f_necro.dat`, навык `skill.necro`)

Цель: труп `i.s.d.n.c.*` или `i.s.d.n.a.*`. Нужно 6 маны, пауза 10 с (`:18-21`). Шанс `necro*5 + int*2` (+10 с `..gt`) (`:26-27`). Зомби `n.z.*`: HP и урон ×0.7, опыт за него 0, без респауна и лута. Живёт `rand(300, 300+(necro+int)*90)` с (`:43-68`). С шансом 4 % даёт +1 опыт некроманту (`:71`). В любой зоне, кроме 0, некромант получает «преступник» (`:72`).

## 6. Смерть и последствия

### 6.1 Общее (`f_kill.dat`)

Выполняется в контексте `f_attackf.dat`, когда HP цели `< 1`:

1. У атакующего сбрасывается цель (`:3`). Всем приходит «<имя> погиб» (`:4`).
2. Создаётся **труп** `i.s.d.<id жертвы>.<5..99>` (`:11-26`) в формате `имя|free_loot|expire|items|butcher_loot`:
   * `free_loot=1`, если жертва преступник (`tcrim`, включая `n.c.*` и держателя флага), животное `n.a.*` или смерть в замке `c.*` (кроме `.in`) (`:17`);
   * исчезает через `g_destroy = 600` с (`:18`, `g.php:41`, удаление в `g.php:566`);
   * `items` содержит **весь инвентарь жертвы**, включая надетое и деньги (`:21`);
   * `butcher_loot` берётся из `osvej` шаблона, его забирают ножом (`:25`).
3. Мародёрство: взять вещь из трупа с `free_loot=0` значит получить «мародер». Исключения: свой труп, одноклановец, супруг, `u.qv` (`f_additem.dat:86`). Список предметов предупреждает «Брать отсюда предметы будет преступлением!» (`f_takediednoid.dat:11`). Квестовые `i.q.*` с чужого трупа игрока взять нельзя (`f_takediedid.dat:5`).

### 6.2 Смерть игрока (`f_kill.dat:28-64`)

* Убийца-игрок получает «убийца», если жертва невиновна, не атаковала его, не одноклановец и не супруг (`:28-32`). Флаг `fcrim` здесь **не проверяется**, так что преступник за такое убийство получает свежие 30 минут с новым титулом.
* Счётчики: `st[1]++` убийце (даже если убийца NPC), `st[2]++` жертве (`:35-37,60-62`).
* Флаг лидерства падает на землю (`:38`).
* **Теряется всё, что было с собой**: `equip` и `items` очищаются, вещи лежат в трупе (`:39-40`). Банк (`bank`), навыки, опыт и знания (`magic`, `priem`) сохраняются. Опыт и навыки при смерти не отнимаются.
* Исключения: **перо жар-птицы** `i.q.pjpt` в рюкзаке (списывается одно перо, остальное остаётся у игрока, труп пустой) и **арена** `arena`, где вещи всегда остаются (`:19,23`).
* Игрок становится призраком `char[8]=1` с HP 0 (`:42`). Лошадь превращается в NPC `n.a.losh.*` с хозяином-жертвой (`:43-54`). После этого `calcparam` (`:63`).
* PvP-записи для доски розыска у офицера `n.officer` (`wanted.dat`):
  * если убийца-игрок был преступником **до начала этой атаки**, а жертва невиновна, у жертвы `war[15] = убийца:` («может назначить награду», `:56-59`);
  * если невиновный убил преступника, у убийцы `war[15] = …:жертва` («может получить награду»), `war[16] = жертва` (`:96-104`).

  Условие `fcrim` вычислено в `f_attackf.dat:54` до `docrim`. Тот, кто стал преступником этим же ударом и сразу убил, в `war[15]` жертвы не попадает.
* **Опыт за игрока не даётся.** Опыт идёт только за NPC.

Призрак (`char[8]=1`) не атакует и не может быть атакован (`f_attackf.dat:6,11`). Он не регенерирует (`g.php:572`), не попадает в списки целей (`g.php:552`), его никто не преследует (`f_goto.dat:15-22`). Он не может использовать предметы (`g.php:188`), брать, бросать и передавать вещи (`f_take.dat:24`). Он может ходить и говорить с NPC `n.h.*` (например, лекарем `n.h.Djozef`).

### 6.3 Воскрешение (`f_ressurect.dat`)

`ressurect()` снимает `char[8]` и ставит `char[5]=time()` (`f_ressurect.dat:6-11`). **HP не восстанавливаются, остаются 0.** Через 30 с регенерации HP начнут расти (§7.1), но до этого воскрешённого убивает любой прошедший уклон удар, даже с уроном 0 (§2.8).

Способы воскреснуть:
* камень воскрешения `i.s.res*`: призрак «берёт» его (`f_take.dat:24`);
* диалог лекаря `n.h.Djozef`: `eval: ressurect(...)`, бесплатно;
* заклинание `m.ressurect` (§5.4);
* живая вода `i.ress` в руках другого игрока с навыком лечения > 0: шанс `rand(1,200) < 40 + healing*10`, вода тратится в любом случае (`plugin/i.ress.dat:12-21`).

### 6.4 Смерть NPC, опыт, респаун

* Убийце `st[0]++` (`f_kill.dat:66-68`).
* **Опыт** (`f_kill.dat:105-112`): игрок получает `war[13]` жертвы в `skills[3]`. Когда `skills[3] > war[13] убийцы * g_exp` (`g_exp=10`), `skills[3]=0`, `skills[4]++` (+1 очко опыта) и `calcparam`. Так как `war[13]` игрока равен сумме навыков, каждое следующее очко требует больше опыта. Для заклинаний и приёмов берётся `war[13]` из подменённого `war`; он копируется из `war` игрока, так что значение то же.
* Сбор предметов по заданию `kvest` (`f_kill.dat:83-86`, см. quests.md).
* **Респаун** (`f_kill.dat:69-82`): если у NPC есть `war[15] = loc:min:max[:snap]` (его ставит таймер спавна, `f_timernpc.dat:10`), в локацию `loc` кладётся таймер на `rand(min,max)` с:
  * без `snap`: строка `id|min:max[|wander]`, NPC появится заново из шаблона, со свежим случайным лутом (`f_timernpc.dat:5-23`);
  * с `snap` (сюжетные NPC: торговцы, офицер, банкиры): полный снимок с полным HP, предметы, `equip` и `osvej` берутся из шаблона.

  Таймеры обрабатываются в `doai()` этой локации (`g.php:537-543`), то есть только когда рядом есть игрок. Без `war[15]` (призванные, зомби, стражники, NPC, поставленные квестом) NPC не возвращается.
* Затем NPC удаляется из локации (`f_kill.dat:89`).

### 6.5 Преступники и стража

**Статус** (`f_docrim.dat`): только для игроков, не в замках `c.N.*` (кроме `.in`) и не на арене. `char[9] = титул`, `char[10] = time() + g_crim - $crim`, где `g_crim = 1800` с (`f_docrim.dat:5-10`, `g.php:42`). Кражи ставят `$crim=600`, то есть статус на 20 минут (`f_useskill.dat:65,85,87`). Снятие происходит по времени в `doai` (`g.php:581`).

Кто делает преступником:

| Титул | Причина | Код |
|---|---|---|
| бандит / живодер | атака невиновного (§2.3) | `f_attackf.dat:60-61` |
| убийца | убийство невиновного игрока | `f_kill.dat:30` |
| мародер | лут чужого трупа | `f_additem.dat:86` |
| вор | неудачная кража | `f_useskill.dat:65,85,87` |
| лечил преступника | лечение преступника или монстра | `plugin/m.heal.dat:32` |
| провокатор | «Безумие» в охраняемой зоне | `plugin/m.maddnes.dat:8` |
| вызвал демона | `m.s.demon` | `plugin/m.s.dat:65` |
| преступник | некромантия в зоне ≠0; питомец-преступник; натравить питомца | `f_necro.dat:72`, `f_owner.dat:5`, `f_speakowner.dat:80` |

**Последствия статуса:**
* любой может атаковать преступника без наказания (§2.3), а его труп можно грабить свободно (§6.1);
* стража: в локации с зоной 1, где есть преступник-игрок или любой `n.c.*` и ещё нет `n.g.*`, на тике `doai` появляется **один** стражник (`g.php:558`, `f_addguard.dat`). Параметры: `HP 200`, меткость 100, урон 30-45, пауза 3, броня 100, уклон 30, маг. уклон/парирование/сопротивление 80/80/70, `алебардой`, опыт 15. Живёт 600 с (`char[11]`), потом исчезает (`g.php:589`). Бьёт случайного из `$crim` (§3.1), преследует в любые зоны, скрытность от него не помогает (`f_goto.dat:8-10`);
* тамплиеры `n.t.*` и пираты `n.p.*` тоже атакуют кого-нибудь из `$crim` (`g.php:597`);
* NPC-преступник (`char[9]`) агрессивен, как монстр (`g.php:598`).

## 7. Регенерация, яд, скрытность

### 7.1 Регенерация (`g.php:571-579`)

На каждом тике `doai`, если прошло `tm = time() - char[5] > 30` с и что-то не полное (или идёт отравление):

```
HP   += round(tm / (30 - regeneration*4)),  не больше hp_max      (NPC: regeneration=0)
mana += round(tm / (30 - meditation*4)),    не больше mana_max
char[5] = time()
```
Призраки не регенерируют. Любое попадание (§2.6) обнуляет отсчёт, так что в бою HP почти не восстанавливаются. Навык `skill.meditation` отдельно даёт `rand(1,meditation)` маны с шансом `meditation*12` (+25 «утром» по игровому времени) (`f_useskill.dat:6-13`).

### 7.2 Яд

* `i.b.jad.c` (яд древесной змеи) ставит цели `char[17] = time()+300` (`plugin/i.b.jad.c.dat:10`) и наносит атаку `ядом` с уроном 0 (`:13,20`). Защиты у `u.ogir`, `u.ascorun`, `u.askorun` зашиты в код (`:11,17`).
* Пока `time() < char[17]`, вместо регенерации HP идёт `HP -= round(tm/10)`, не ниже 1 (`g.php:576`). **Яд не убивает.** Мана регенерирует как обычно. Экран игрока искажается подменой букв (`g.php:471-497`), в статусе «отравлен» (`g.php:227`).
* Противоядие `i.b.antidot` сокращает отравление на 300 с (`plugin/i.b.antidot.dat:5-9`).
* `i.b.jad` (бутылка с ядом) ничего не отравляет: это обычная атака `ядом` 1-28 (`plugin/i.b.jad.dat:7`).

Остальные бутылки: `i.b.fire` (1-24 по всем в локации), `i.b.holy` (6-24 по всем преступникам и `n.c.*`), `i.q.pdeath` (0-90 по всем, не в банке), `i.q.ssword` (0-90 одной цели, обычная физическая атака, нужны str 5 и dex 4). Все, кроме `ssword`, идут с `$rmagic=1`, то есть по магической ветке без учёта брони. `i.b.bomb`, `i.b.hlop`, `i.b.pit` только пишут шуточный текст в журнал.

### 7.3 Скрытность и бой (навык `hiding`, `skills[17]`)

* Агрессоры выбирают игрока целью с вероятностью ≈`1 - 6*hiding/100` (`g.php:552`).
* Уход от погони с шансом `hiding*4 + dex` %, не от стражи (`f_goto.dat:10-13`).
* С шансом `hiding*8` % уход из локации не пишется в журнал (`g.php:132`, `addnpc(...,$hide)` в `g.php:644`). Приход в локацию пишется всегда.
* Больше скрытность на бой не влияет: в бою нет невидимости, скрытой атаки или бонусов.

## 8. Пример: новичок с ножом против крысы

**Персонаж.** Сразу после регистрации (`f_site_reg2.dat:22-26`): `str=dex=int=1`, все навыки 0, `skills[4]=2`, HP и мана 20/20, в рюкзаке `i.w.k.begin` («нож», `0-2`, требований нет, `speed 4`, `ножом`). Нож нужно надеть (`use` без цели). `calcparam` даёт:

```
war[0] = 10*(dex+cw) = 10            (без оружия было бы 10*(1+0+2) = 30)
war[1..2] = 0+1 .. 2+1 = 1..3         (без оружия 0..2)
war[3] = 4 - round(1/2) = 3 сек       (без оружия 5-1 = 4)
war[5] = 0, war[6] = 1+0+0 = 1, war[7] = 0 (нет щита), war[9..11] = 0
war[13] = 1+1+1+2 = 5  → для очка опыта нужно skills[3] > 50
```

**Противник.** Ближайшие монстры `n.c.*` к старту `_begin` находятся на складе `x1167x583` (зона 0): `n.c.rat.sk3` и `n.c.pauk.sk3` с респауном 300-600 с. Крыса `n.c.rat`: HP 6, меткость 70, урон 1-4, пауза 4, уклон 5, опыт 2, лут `i.money 0-3`, разделка `i.f.meat`.

**Удар игрока по крысе:**

| Шаг | Расчёт | Вероятность / значение |
|---|---|---|
| попадание | `rand(0,100) <= 10` | 11/101 = 10.9 % |
| не уклон | `rand(0,100) > 5` | 95/101 = 94.1 % |
| урон | `rand(1,3) - rand(0,5)`, не ниже 0 | в среднем 0.556; > 0 только в 1/3 случаев |
| щит, броня | у крысы нет | — |
| крит | 2/101 при уроне > 0 | ×1.02 |
| **итого за удар** | | **≈0.058 HP**, то есть ≈0.019 HP/с при паузе 3 с |

Чтобы снять 6 HP, нужно в среднем около 100 ударов, то есть примерно 5 минут непрерывного боя (без учёта регенерации крысы, +1 HP за 30 с без попаданий). Голыми руками: `31/101 * 0.941 * 0.222 ≈ 0.065` HP за удар раз в 4 с (≈0.016 HP/с), ещё хуже.

**Крыса по игроку** (на каждом тике `doai`, когда не отдыхает; плюс ответ на каждый удар игрока, если в этот момент свободна):

| Шаг | Расчёт | Значение |
|---|---|---|
| попадание | `rand(0,100) <= 70` | 70.3 % |
| не уклон | `rand(0,100) > 1` | 98.0 % |
| урон | `rand(1,4) - rand(0,5)`, не ниже 0 | в среднем 0.833 |
| **итого** | | **≈0.59 HP за атаку**, ≈0.15 HP/с при паузе 4 с |

20 HP новичка кончатся примерно за 34 атаки крысы, это чуть больше 2 минут. Новичок почти наверняка проигрывает крысе. Главная причина: постоянный штраф `-rand(0,5)` к урону (§9, п. 1). Без него нож наносил бы ≈0.21 HP за удар (≈29 ударов, ≈1.5 мин), а крыса ≈1.76 за атаку.

Бесплатные очки опыта меняют немного: при сумме навыков 5 учитель обучает бесплатно (`f_speakskillup.dat:127`). `+1 cw` даёт меткость 20 (21/101), `+1 str` даёт урон 2-4, HP 30 и уклон 3.

Опыт: за крысу 2. При пороге `> 50` очко опыта наберётся после 26 крыс.

## 9. Странности и ошибки

1. **Урон всегда уменьшается на `rand(0,5)`** (`f_attackf.dat:89`). Условие `$tchar[9] && ($time>=20 and $time<=0) || ($time = 00.00 and $time<8)` никогда не истинно. Первая скобка невозможна: `>=20` и `<=0` одновременно. Во второй стоит присваивание `=`, а у `and` приоритет ниже `=`, поэтому выражение равно `0.0 and …` и ложно. Задуманная «ночная прибавка по преступникам» не срабатывает никогда, и всем атакам, включая заклинания, стражу и бутылки, достаётся только ветка `else` со штрафом. Для слабого оружия это больше половины урона (§8).
2. **Опечатка `$tсhar`** с кириллической «с» в `f_attackf.dat:170`: NPC всегда переключается на последнего ударившего, даже если был занят другим. Опечатка есть и в исходном cp1251-файле, это не артефакт нормализации.
3. **Ответный удар бесплатный.** Ответ `attack(to,from,0,0)` не ставит паузу (`f_attackf.dat:27,171`), поэтому свободная цель получает лишний удар на каждый инициативный удар противника. Для игроков это автоматическая контратака без действия с их стороны.
4. **`?attackf=1` отключает весь бой в запросе** (`g.php:610-612` плюс `extract($_GET)` в `g.php:3`). В том числе атаки NPC по игроку в `doai`. Похоже на уязвимость **(не проверено в запуске)**.
5. **NPC не используют приёмы**, хотя код для этого есть: `f_mobpriem.dat` не подключён, а `$use="p.p"` в `f_attackf.dat:29` мёртвый.
6. **`m.charm.enemy` (Привлечь) не работает никогда**: `!substr($to,0,4)=='n.g.'` из-за приоритета `!` всегда ложно. Кроме того, сообщение «не подействует» выводится всегда, потому что у `if` нет `else` (`plugin/m.charm.enemy.dat:4,12`).
7. **Воскрешение с 0 HP** (`f_ressurect.dat`). Описание `m.ressurect` («с минимумом здоровья») формально верно, но при 0 HP персонаж погибает от любого удара, прошедшего уклон, даже с уроном 0.
8. **Расхождения со справкой `content/raw/desc` и описаниями предметов:**
   * `p.d.u`: в описании «+30 %», в коде +35 (`f_attackf.dat:37`).
   * `p.d.o`: в описании «уменьшает на 60 % любой урон». В коде это срабатывает с шансом «меткость − штраф int» и не действует на заклинания (`f_attackf.dat:44`).
   * `p.d.re`: в описании снижение своего урона «на весь период». В коде стойка (и снижение) снимается первой же физической атакой по владельцу (`f_attackf.dat:38,43`).
   * `p.p`: в описании «против этого приёма не существует блока или защиты». На самом деле действуют уклон, щит, броня и стойки `p.d.o/re/p`.
   * `m.w.vamp`: в описании «не действует на преступников и монстров». Действует на всех (`plugin/m.w.dat:21-22`).
   * `skill.coldweapon`: «учитывается сила». Сила влияет на урон, а не на меткость. `skill.str`: сила прибавляется к урону «холодного оружия (кроме арбалетов)», хотя в коде к любому оружию, включая луки и посохи, кроме арбалетов.
   * `weapon.int`: «урон меньше на удвоенную разность». У посохов (`verb=магией`) −4 к min и −5 к max за единицу (`f_calcparam.dat:62-63`).
   * `magic.period`: в справке сила удлиняет период любого заклинания. В коде только `m.w.*` (`f_usemagic.dat:38`).
   * Самоцветы: `i.i.gt` в описании «навык некромантии +10 %». На деле +10 к шансу некромантии и одновременно +10 с к паузе атаки. `i.i.kr` «крит +5 %» даёт только +10 маны. `i.i.kp` даёт +10 маны и +4 (а не +5) к шансу крита. `..fa/..jd/..ld` («урон огнём/ядом/холодом») дают просто +5 к макс. урону.
   * `skill.necro`: преступлением считается некромантия «в пределах города». В коде в любой зоне ≠0, то есть и в цитадели и форте на острове (`f_necro.dat:72`).
   * `docs/data-fields.md` (§4.1) утверждает, что нападение на животное в охраняемой зоне считается преступлением. При прямой атаке это не так: условие закомментировано (`f_attackf.dat:60`). Правило срабатывает только при натравливании питомца (`f_speakowner.dat:80`).
9. **Сила снижает магическую защиту и увеличивает физический уклон и парирование** (`f_calcparam.dat:15-19`). В справке `skill.uklon/parring` это упомянуто, у магической защиты нет.
10. **Нож новичка хуже кулаков по меткости**: 10 против 30 (§8), потому что у безоружного `+2` к `dex+hand` (`f_calcparam.dat:94`).
11. **Интеллект ухудшает приёмы**: `-(int-1)*10` к меткости (`f_usepriem.dat:25`). Это задокументировано в `desc/p`, но выглядит как задуманный антисинергетический штраф для магов, а не ошибка.
12. **Эффекты самоцветов на паузу атаки (`war[3]`) зависят от порядка `equip`** и пропадают без оружия (§1.6).
13. **Проваленное боевое заклинание всё равно делает преступником** (`f_usemagic.dat:56` → `m.w.dat` с `$loss` → `f_attackf.dat:59`). Мана и период при провале тратятся.
14. **Счёт «убито игроков» (`st[1]`) растёт и у NPC-убийц**, а комментарий `// +1 монстр` у `st[2]` (смерти жертвы) неверен (`f_kill.dat:36,61`).
15. **Перо жар-птицы на арене**: там всегда выполняется ветка «спасает свои вещи пером жар-птицы» с сообщением всем, даже без пера (`f_kill.dat:19,23`). При этом у трупа пропускается поле `items` (строка трупа сдвигается).
16. **Стражник создаётся с испорченным `char[5]`**: `time().'1'` вместо `time().'|1'` даёт метку регенерации в 10 раз больше текущего времени. Стражник не регенерирует, а `char[6]` у него пуст (`f_addguard.dat:7`).
17. **Опыт питомца уходит `owner[1]`** (за кем следует), а не хозяину `owner[0]`. У «привлечённых» (`owner[1]=0`, если бы заклинание работало) и у питомцев, оставленных «стоять» (`owner[1]=""`), опыт ушёл бы в никуда (`f_kill.dat:125-133`).
18. **Паузы заклинаний не ограничены снизу** (`f_usemagic.dat:35`). При `cast_time + 3 - dex <= 0` отдыха нет. В текущих данных минимум 2 с (`m.kon`), но у `m.qv` `cast_time=-3600`.
19. **Приёмы в банке, вероятно, запрещены всегда**, даже против преступников: проверка `f_usepriem.dat:3` скопирована из `f_attackf` и опирается на неопределённые переменные **(не проверено)**.
20. **Бегство NPC** происходит только в локации игрока, сделавшего запрос (`g.php:586`, `$loc==$i`). NPC в соседних локациях при низком HP не убегают.
