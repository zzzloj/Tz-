# Новый движок «Территории Зла»

Kotlin Multiplatform: сервер на Ktor, общий модуль и нативные приложения — Android (Jetpack Compose) и iOS (SwiftUI). Почему так — `docs/engine-options.md`. Правила игры, которые нужно перенести, — `docs/mechanics.md`, квесты — `docs/quests.md`, данные мира — `../content/`.

## Модули

| Модуль | Что это |
|---|---|
| `shared/` | Общий код для сервера и приложений: протокол (`Protocol.kt` — что сервер отдаёт клиентам), клиент API на Ktor (`GameApi`), логика экранов (`Explorer`). Собирается для JVM, Android и iOS (XCFramework `Shared`). |
| `server/` | Игровой сервер на Ktor. Загружает `content/`, проверяет его (выходы в несуществующие локации, переходы диалогов в несуществующие темы) и отдаёт API. Сервер — единственный источник правил: клиент только показывает и отправляет действия. |
| `androidApp/` | Приложение Android на Jetpack Compose поверх `shared`. |
| `iosApp/` | Приложение iOS на SwiftUI поверх `Shared.xcframework`. Проект Xcode генерируется из `project.yml` (XcodeGen), в репозитории не хранится. |
| `ci/annotate.py` | Превращает ошибки сборки из лога CI в аннотации GitHub. |

## Что уже работает

**Этап 13 — сайт, аккаунт, модерация, сохранение мира**

- Аккаунт в приложениях: смена пароля (другие устройства отключаются), «О себе» (видно при осмотре персонажа), код восстановления вида `ABCD-EFGH-JKLM-NPQR` — показывается один раз, по нему «Забыли пароль?» задаёт новый пароль (почты нет), удаление аккаунта с паролем. Токен на Android теперь зашифрован ключом из Android Keystore.
- Роли `player` / `moder` / `admin`; администраторы — логины из переменной `TZ_ADMINS` (через запятую), модераторов назначает администратор. Модератор: мут (запрет чата, писем и форума — старое «Бан!»), выгнать, бан до суток, телепорт себя или игрока по списку мест старой админки, призвать игрока, объявление всем. Администратор ещё: бан навсегда и снятие бана, выдача предметов, роли. Всё пишется в журнал `mod_log`, забаненный не может войти, его сессии удаляются.
- Форум (как старый `forum/`): разделы «Новости» (темы открывают только модераторы), «Общий», «Вопросы и помощь», «Кланы и замки», «Торговля», «Ошибки и предложения»; темы, ответы, правка своих сообщений, страницы по 20, пауза 10 секунд между сообщениями, повтор не принимается; модераторы закрывают, закрепляют, переименовывают, удаляют. Читать можно без входа.
- Страницы из `content/pages/*.md`: об игре, как начать, правила, вопросы, флаг лидерства, история. Доска объявлений в городе (`i.s.book.news`) показывает последние новости форума, книжная полка (`i.s.book.story`) — страницы.
- Сайт на том же сервере (`/`): новости, кто в игре, замки и кланы, страницы, форум для чтения.
- Мир переживает перезапуск: раз в 2 минуты и при остановке сервера (SIGTERM при деплое) в `world_snapshot` пишутся NPC с их местом, здоровьем, товаром и хозяевами (питомцы, лошади, наёмники), вещи на земле, трупы, таймеры возрождения убитых, рудные жилы. При старте снимок накладывается на мир из `content/`: NPC из контента берут параметры из контента, убитые ждут своего возрождения, новые NPC контента появляются.
- Бэкапы: `.github/workflows/engine-backup.yml` каждую ночь делает `pg_dump`, шифрует его (репозиторий открытый) и хранит 30 дней; нужны секреты `DATABASE_PUBLIC_URL` и `BACKUP_PASSPHRASE`. Второй вариант — расписание бэкапов тома Postgres в Railway (вкладка Backups).
- Смоук после деплоя проверяет сайт, форум, код восстановления и удаляет свой аккаунт.
- Не перенесено: платные аккаунты, SMS-дублоны, фотогалерея.

API: `POST /api/auth/recover`, `GET|POST /api/account` (op: password, recovery, about, delete), `GET|POST /api/admin`, `GET /api/forum`, `GET /api/forum/section/{id}?page=`, `GET /api/forum/topic/{id}?page=` (−1 — последняя), `POST /api/forum`, `GET /api/pages`, `GET /api/pages/{id}`; `GET /api/me` отдаёт роль.

**Этап 12 — общество и квесты** (`Society.kt`):

- флаг лидерства: один на мир, лежит на Центральной площади, поднять может любой живой; у держателя +10 к здоровью, +20 к заклинаниям, +10 к приёмам, но напасть на него может любой без преступления. Теряется при смерти, если бросить или уйти из игры (из комнат таверны — в зал);
- свадьба у Лаймы: предложение, согласие, нужны золотые кольца у обоих и два свидетеля, молодожёнам — букеты; развод за 500 монет. Супругов нельзя «убить преступно» и ограбить мародёрством; если супруга ранили — у второго кнопка «на помощь» на 5 минут; «Женат на…» при осмотре; брак расторгается, если второй больше не считает себя в браке;
- гильдия воров: заказ на случайного игрока онлайн (нужно не меньше 30 в игре, как в оригинале), за выполнение 1000 монет, перчатки вора и 100 опыта; благословения Томрака (броня +5, здоровье +10); букеты: цветы собираются в букет, до 5 видов; заказ Греда на большой букет — каменный цветок; флакон демона стихий у чёрного алтаря; заказы «убей и собери»;
- замок: если в замке вашего клана чужие — кнопка «в замок»;
- «Мир»: кто в игре с уровнем, кланы по числу членов, владельцы замков, где флаг; «Карта»: все локации своей части света точками (основная земля, Ансалон, Волчий остров), вы, флаг, замки;
- почта: «написать всем» контактам;
- все темы диалогов переведены: SMS-услуги 2007 года (дублоны у Кениуса, код у Рене) честно отвечают, что больше не работают. Ключи комнат таверны и хранилищ замков не переносились: ни один диалог старой игры их не выдавал.

**Этап 11 — подчинённые** (`Pets.kt`):

- питомцы у Милты (собака, сокол, лошадь, корова, свинья — одно купленное животное на лавку), лошади у Мартена и Свана, овца у Вильяма; ручной питомец идёт за хозяином в соседнюю локацию (не больше трёх подчинённых одного персонажа в одном месте), без прогулок час — уходит;
- разговор со своим («говорить»): защищай меня / не лезь в драку / атакуй… / защищай…, следуй за мной / стой здесь / следуй за…, приласкать (продлевает срок), состояние (точность — от изучения животных), изменить имя, расстаться. Натравить на невиновного — преступление хозяина, чужого питомца бить — «живодер»;
- лошадь: «Сесть в седло», верхом — «галопом» через две локации по одной подписи, штрафы всадника (стрельба −10, кулаки −20, заклинания −10, приёмы −10, по всаднику попадают на 10 хуже). Спешился — лошадь рядом на час; «Сбить с коня» и приём «выбить с седла» работают; погибший всадник оставляет лошадь;
- наёмники: у Маркуса воин на 3/6/9 часов и маг на 3 часа, у Лансета личные наёмники на 3 часа; фея у Михаила за очки опыта лечит хозяина каждые 20 с; отряд Кастена на прорыв; сопровождение Йофе из темницы;
- приручение (навык × изучение животных), зачарование (1–5 минут), призыв волка, скелета, голема, фантома, тучи, дерева (у деревьев), волны (у воды), демона (с преступлением), свиток призыва; некромантия: труп монстра или животного встаёт зомби на 5–20 минут;
- половина опыта за убийство питомцем, призванным или зомби идёт тому, за кем он следует; квесты с животными: пёс Яна, единорог Мартена, овца для гильдии магов.

**Этап 10 — навыки, предметы и осмотр** (`Skills.kt`, `Look.kt`, миграция V9):

- кража (`POST /api/game/skill`): сначала «подглядеть» (шанс 6·(ловкость + подглядывание − осторожность цели), у NPC осторожность 3), потом минуту можно «украсть» увиденное — всю стопку, надетое вдвое труднее. Провал — «вор» на 20 минут, NPC нападает. Нельзя в банке, на арене и у того, с кем деритесь. Перчатки вора — подглядеть без броска;
- медитация: навык·12 % на +1…навык маны, 5 с;
- осмотр (`POST /api/game/look`, кнопка «?»): игрок (пол, дни в игре, ранг «Новичок … Лорд» и титул по лучшему навыку, телосложение, клан, экипировка, статистика), NPC (тип, говорит ли, сложность приручения), предмет (урон, требования, скорость, заточка, мастер, самоцветы, особые тексты), заклинание (шанс, урон и скорость с вашими характеристиками), приём, справка по навыкам;
- статистика персонажа: убито монстров и игроков, смертей, краж, рыбы, веток, руды, самоцветов найдено и вставлено;
- страница «Персонаж»: ранг, титул, все защиты, навыки со справкой;
- в бою теперь считаются заточка оружия (до +6), адамантовый комплект и комплект огра и тролля, амулет власти (двойной урон по монстрам), самоцвет с шансом крита;
- перо жар-птицы: при смерти сгорает, а вещи остаются у призрака;
- квестовые вещи нельзя выбросить (обход запрета на передачу закрыт); носить можно не больше одного пера и одного порошка смерти, двух стеклянных мечей;
- взять или бросить можно одну штуку из стопки; разделка трупа иногда даёт опыт, как в оригинале.

**Этап 9 — мир и перемещение** (`Travel.kt`):

- запертые проходы старой игры снова заперты: ворота замка Дитриха («Стражник: Стой!» — только по квесту), шахта гномов, проход к `x1746x545` и зеркальный переулок — по ключу `i.q.keykrep*`;
- в журналах «X ушёл на север» / «Пришёл X» (для NPC тоже); со скрытностью уход с шансом hiding·8 % незаметен; «Вы на охраняемой территории» / «Вы покинули охраняемую территорию»;
- «звуки»: выход помечен «!», если за ним кто-то есть;
- лодка: «Куда плыть?» — к причалу (лодка опять течёт), в Ансалон, к морю; лодка плывёт с вами;
- погоня: NPC идёт за целью в соседнюю локацию той же зоны, городская стража — в любую; уйти можно с шансом hiding·4 + ловкость % (от стражи нельзя). Мир «тикает» и в соседних с игроками локациях, как `doai()` в оригинале;
- монстры не замечают игрока со скрытностью в hiding·6 % тиков; жар-птица улетает, как только кто-то приходит;
- навыки «Регенерация» и «Медитация» ускоряют восстановление здоровья и маны;
- яд древесной змеи: 5 минут здоровье убывает (не ниже 1), противоядие снимает 5 минут. Бутылки и разовое оружие: огненная (по всем), святая вода (по преступникам и монстрам), яд, порошок смерти, стеклянный меч;
- у людей видно здоровье в процентах, кого атакует, тамплиер или пират на Волчьем острове; у NPC — кого атакует;
- после перерыва (10+ минут без действий) персонаж просыпается вне арены, комнат замка и таверны, а срок преступления за время отсутствия не идёт.

**Этап 8 — магия и приёмы** (`Magic.kt`):

- заклинания из книги (`POST /api/game/cast`), свитки `i.m.*` (сгорают) и руны заклинаний `i.r.*` (остаются) — через «использовать» с целью. Шанс, мана, пауза и период — по формулам `f_usemagic.dat`: навык магии и интеллект помогают, сила мешает, без навыка магии не прочесть даже свиток;
- боевые заклинания `m.w.*` бьют магией (броня не спасает, ответного удара нет), `m.w.a.*` — всех вокруг, «святые» — только преступников и монстров, «Удар» выжигает ману, «Вампиризм» лечит мага; сорвавшееся боевое заклинание всё равно делает преступником;
- лечение (на себя, другого, NPC; «Лечение всех» — себя, клан и стражу своего замка; лечить преступника — преступление), «Рой мошек» (оглушение 20 с), «Безумие» (в городе с шансом 80 % безумцем и «провокатором» становится сам маг), «Мир» и «Тишина», «Броня», «Сила», «Мана» (держатся до смены экипировки), «Медитация», «Воскрешение», «Создать еду», «Букет», «Поиск» по соседним локациям;
- руны телепортации: пустую руну помечают «Пометить», по помеченной переносит «Возвращение» или руна сама (7 маны), «Портал» открывает проход на 3 минуты для всех. Запреты старой игры: арена, таверна, Волчий остров, замки;
- приёмы (`POST /api/game/technique`) с периодом каждого: быстрый, двойной, мельница (бьёт всех вокруг), меткий, по ногам (оглушение 15 с), по рукам (оружие падает на землю), выбить щит, в голову, в прыжке, сильный. Интеллект снижает меткость приёмов, как в оригинале; со стрелковым оружием приёмов нет;
- защитные стойки `p.d.*`: уклон от стрел, реакция, щит, глухая оборона (весь срок отдыхаете и не берёте вещи), сбить заклинание и концентрация, защита головы, ног, рук, седла — работают против первой подходящей атаки;
- в банке можно драться, если один из двоих преступник (было: нельзя никогда);
- позже: призыв, зачарование, «Сбить с коня» и приём «выбить с седла» (с питомцами и лошадьми), бонус флага лидерства; NPC, как и в оригинале, приёмов и заклинаний не используют.

**Этап 7 — бой между игроками и закон** (`Pvp.kt`, миграция V8):

- атаковать можно любого игрока и любого NPC на локации (кнопка «атаковать» у людей). Жертва сразу отвечает ударом, если не отдыхает, — это самооборона, не преступление;
- преступления на 30 минут (`Rules.CRIME_SECONDS`): «бандит» — удар по невиновному игроку или мирному NPC, «убийца» — убийство невиновного, «мародер» — взять вещь из чужого трупа невиновного (не своего и не клана), «живодер» — удар по чужому наёмному стражнику. Звание видно в шапке персонажа и рядом с именем у других, со счётчиком минут; у трупа предупреждение «взять отсюда — мародёрство»;
- невиновен тот, кто сам не преступник, не напал на вас первым и не из вашего клана; на Волчьем острове (Y ≥ 1099) пираты и тамплиеры воюют без преступлений;
- стража города: на улицах зоны 1, где есть преступник или монстр, появляется стражник «… [стража]» (100 HP, алебарда 30–45) и нападает; уходит через 10 минут. Тамплиеры бьют пиратов и преступников в своей зоне, пираты — тамплиеров, стражники замков — чужих в замке;
- в банке драться нельзя; в замках и на арене преступлений нет. Свой клан в своём замке получает +0–10 к урону;
- смерть от игрока: вещи остаются в трупе на 10 минут, как от монстра; трупы преступников и погибших в замке — ничьи;
- арена (букмекер Дэн на Центральной площади): вход — 1000 монет, они лежат на полу арены и достаются последнему живому. Погибшие на арене сохраняют вещи; выйти можно через камень выхода призраком или оставшись одному;
- награды за голову у офицера в банке: убитый преступником может назначить награду за убийцу (любую сумму), список наград, получить награду за убитого преступника;
- замки: чужой может войти в защищённый замок — это нападение, владельцам приходит «На ваш замок … напали!», стражники ворот атакуют его;
- пока нет: захвата замка боем как отдельной механики (захватывают по-прежнему, войдя в замок без защитников), кражи, магии.

**Этап 6 — замки кланов без боя** (`Castles.kt`):

- пять замков `c.1..c.5`, состояние в таблицах `castles`, `castle_guests`, `castle_guards` (в старой игре оно было зашито в название локации ворот). На старте все свободны: кланов 2007 года нет;
- захват: член клана входит в ворота чужого или ничьего замка, где нет защитников (стражи `n.o.*`, живых членов клана-владельца и гостей), — замок его клана, ворота 2 часа нельзя запереть, прежние хозяева извещаются, контракт хранителя сбрасывается. С этапа 7 вход в защищённый замок — нападение, стража бьёт чужих;
- стража: у Лансета (Замок Дитриха) за 20–70 монет — стражник сразу встаёт у ворот замка своего клана (в оригинале его надо было довести за 30 минут; сопровождение — с питомцами), контракт сутки, продление у самого стражника 50/60/70/100 в день. Диалог стражника: «иди» по залам, «запереть ворота» на 10 часов (потом 8 часов нельзя), гости — впустить ожидающего у ворот и убрать из списка;
- у ворот (`c.N.in`): кто владеет, заперто ли, вывеска; «постучать» (раз в 3 минуты, клану-владельцу приходит сообщение), «открыть ворота» и вывеска для хозяев. Призрак не может войти в чужой замок;
- хранители (Босвар, Саварон, Зидван, Антарес, Валор): глава клана за 500 монет и руну заключает недельный контракт, члены клана телепортируются. Исправлено: хранители замков 1 и 2 отсутствовали в мире 2007 года — теперь стоят на месте;
- пока нет: сопровождения, арендных комнат хранилищ (в оригинале их не выдавал ни один диалог), флага лидерства.

**Этап 6 — общение и кланы** (`Social.kt`):

- речь в локации `POST /api/game/say` `{"text", "channel": "here"|"clan"}`: до 250 символов, фильтр как в старой игре, но без ложных срабатываний (старый глушил любое слово с «ху»), повтор той же фразы запрещён; призрака слышат по навыку спиритизма (остальным «Ooo…»);
- личные сообщения `GET/POST /api/messages`: контакты добавляются рядом, писать можно тому, у кого вы в контактах (правило оригинала против спама); сообщения доходят и до тех, кто не в игре (в старой — только онлайн), хранятся 30 дней, до 100 на игрока. Переписка **не** пишется в общий лог, как было с `x_konti.txt`;
- обмен между игроками `POST /api/game/exchange` `{"op": "start"|"add"|"remove"|"agree"|"cancel"}`: любое изменение снимает согласие обоих, передача одной транзакцией (старая могла оборваться посередине), квестовые предметы нельзя, кроме дублонов и перьев жар-птицы;
- кланы: регистрация у Мирандера (50 000 монет, имя вводится в диалоге, камень гильдии), `GET/POST /api/clan`: приглашение того, кто рядом, вступление, ранги (сеньор, сенешаль, вассал, неофит), исключение, передача главенства, выход и роспуск, описание; управлять может глава или сенешаль с камнем гильдии. Клан виден рядом с именем, клановый чат в сообщениях. Клан хранится в базе, а не в файле портала с паролем главы;
- в приложениях: «Почта (N)», «Клан», строка «Сказать всем/клану», у игроков рядом — «обмен», «в контакты», «в клан».

**Этап 5 — торговля, банк, крафт** (`Economy.kt`, `Crafting.kt`, `../content/crafting.json`):

- торговцы: вариант диалога «покажи товары» / «продать» открывает список (`GameView.shop`), покупка и продажа — `POST /api/game/shop` `{"npc", "mode", "item", "count"}`. Цены как в старой игре: `round(цена · кол-во · множитель)`, множитель 1 для вещей ценой 1, руны по 50; товар обновляется при просмотре раз в период ±30 %; фильтры скупки; `buy2` Кениуса за дублоны; Натан — только с грамотой Хагена или лентой Дитриха;
- банк: одна ячейка на персонажа у всех банкиров (`POST /api/game/bank` `{"npc", "op": "put"|"take", "item", "count"}`), не больше 70 000 монет и 40 разных предметов, плата 20/200 у банкиров тамплиеров/пиратов и только для своей фракции (в старой игре проверка стояла лишь в списке). Банк у Привратника Уина (ошибка оригинала) не переносится;
- использование предметов `POST /api/game/use` `{"item", "recipe", "target"}`: еда и зелья (50 видов), крафт по таблицам (кузнец, луки, плотник, ткач, кожевник, копчение, алхимия, стрелы и болты, леска — 64 рецепта, именные изделия `…_Имя_`), добыча руды с самоцветами и големом, рубка веток, рыбалка, жилы и деревья с запасом и восстановлением, бинты, живая вода (воскрешает призрака игрока), ножницы, костёр и жарка, наполнение бутылки, шлифовка, инкрустация и извлечение самоцветов, заточка, распаковка, шуточные предметы. Данные — `content/crafting.json` (описание и исправления ошибок оригинала — `content/crafting.md`);
- пока нет: обмена между игроками (с чатом, этап 6), букетов и перчаток вора (с кражей).

**Этап 4 — диалоги и квесты** (`Dialogs.kt`, `Game.kt`, `../content/logic/`):

- разговор с NPC: `POST /api/game/talk` `{"npc", "topic", "arg"}` возвращает экран с открытым диалогом (`dialog`: реплика и варианты). Открыть можно только `begin` или вариант, показанный последним, — в старой игре любую тему открывали прямо по ссылке `&id=`;
- весь PHP из диалогов (286 вставок `eval:` в 87 диалогах и 6 PHP-диалогов замков) переписан в декларативные условия и действия — формат в `content/logic/README.md`, проверка без JVM — `tools/content/check_logic.py`, в тестах — `DialogTest`. Старый движок эти файлы не читает;
- задержки квестов собраны в одном файле `content/logic/timers.json` (29 штук): `scope: world` — общая для всех (масштабные квесты: служба у барона, один клевер на мир), `player` — у каждого своя (обмены, доставки);
- учителя: атрибуты и навыки за очки опыта (для новичка бесплатно, пределы 5 и суммы 12/50, выбор, что понизить), заклинания и приёмы за деньги (запоминаются, применение — с этапом магии). Навыки хранятся в `characters.skills`;
- исправлены ошибки квестов из `docs/quests.md`: награда больше не выдаётся без сданного предмета, неверные id и переходы, общий кулдаун мелких заданий стал личным и т. д.;
- 73 темы ждут механик следующих этапов (питомцы и наёмники, кланы и замки, PvP и награды за голову, свадьбы, арена, сопровождение): в них игрок видит «Этот разговор пока не перенесён», список — `untranslated` в `GET /api/content/report`;
- торговля и банк (`buy`, `sell`, `tobank`) — этап 5, варианты с ними пока скрыты.

**Этап 3 — бой** (`Combat.kt`, `Game.kt`):

- параметры персонажа — порт `f_calcparam.dat` (без камней, заточки, комплектов и флага — их ещё нет в игре); паритетный тест `CalcparamParityTest` прогоняет 400 случайных персонажей через настоящий PHP-файл старой игры и через Kotlin и сравнивает всё поле `war`;
- удар — как `f_attackf.dat`, в том же порядке бросков: попадание, урон, уклон, парирование щитом (для магии — сопротивление), броня, крит (2 %, стрелковое 5 %, магия 4 %); пауза после удара; бесплатный ответный удар цели, которая не отдыхает; стрелы расходуются;
- исправлена явная ошибка старого боя: убрана поправка «время суток» (из-за бага всегда −0…5); NPC бьёт в ответ всех, кто его ударил, — его удары идут по очереди по всем нападавшим в локации;
- NPC сами: монстры `n.c.*` нападают на игроков в своей локации, раненые (<25 % HP) убегают с шансом 50 %, регенерация игроков и NPC — `round(t/30)` после 30 с без ударов;
- смерть как в оригинале: всё, что было у персонажа, падает в труп на 10 минут, персонаж становится призраком (ходит, но не дерётся и не берёт вещи), воскрешение у камня `i.s.res*` или у лекаря `n.h.*` (двор лекаря к северу от Переулка) с 0 HP, как в оригинале, — здоровье восстанавливается со временем; убивает только попавший удар;
- смерть NPC: его вещи в трупе, мясо и шкуры — «разделать» ножом (`i.w.k.*` в рюкзаке), появление снова по таймеру `respawn`; опыт `exp_value` убитого, очко опыта сверх `сумма навыков × 10`;
- пока без стражи и преступлений, поэтому атаковать можно только монстров `n.c.*` и животных `n.a.*`; PvP, приёмы и магия — позже;
- события в реальном времени: WebSocket `GET /api/events` (тот же токен в заголовке) присылает «экран изменился», приложения перечитывают `GET /api/game`; журнал боя — последние 30 строк.

API этапа 3: `POST /api/game/attack` `{"target": "<npc>"}`, `/loot` `{"corpse": "c1", "item": "<id>"}`, `/butcher` `{"corpse": "c1"}`, `/resurrect`.

**Этап 2 — мир живёт** (`World.kt`, `Game.kt`):

- мир в памяти сервера строится из `content/`: 420 NPC, уже стоящих в локациях (питомцы и наёмники игроков 2007 года не переносятся), и таймеры появления (166 NPC, 40 предметов) — срабатывают при старте;
- блуждание NPC по таймеру сервера (тик раз в секунду): случайный выход в локацию той же зоны, не дальше `steps` шагов от дома, обратно по следу (как `f_na.dat`);
- предметы на земле: брошенное исчезает через 10 минут (`g_destroy`), истёкшие предметы архива 2007 года не появляются, неподвижные объекты (`i.s.*` — деревья, таблички) видны, но не берутся; таймеры предметов пополняют их;
- инвентарь в PostgreSQL (`character_items`): стартовый нож у нового персонажа (и у созданных раньше), взять / бросить / надеть / снять; слоты: одно оружие, одна вещь на слот брони (`i.a.b.`, `i.a.h.`, …), щит несовместим со стрелковым оружием;
- на экране: кто здесь (NPC), игроки рядом (активные за последние 10 минут), что лежит, инвентарь; кнопка «осмотреться» перечитывает мир.
- Пока не сохраняется: живое состояние мира (после перезапуска NPC снова на местах из `content/`, брошенное и трупы пропадают).

API этапа 2: `POST /api/game/take`, `/drop`, `/equip`, `/unequip` с телом `{"item": "<id>"}`; `GET /api/game` возвращает и инвентарь.

**Этап 1 — аккаунты и персонаж** (сервер на Railway: `https://tz-engine-production.up.railway.app`, база — сервис `Postgres` в том же проекте):

- регистрация и вход, токен сессии (в базе хранится только SHA-256), пароли в bcrypt, ограничение неудачных входов, зарезервированные логины старых админов;
- персонаж: имя из букв одного алфавита (смешанные «Aнтoниo» не пройдут), пол, стартовые параметры как в старой игре (атрибуты 1, HP и мана 20, 2 свободных очка), старт в `_begin`, один персонаж на аккаунт в мире;
- перемещение только по выходам текущей локации — сервер проверяет, позиция сохраняется;
- приложения: вход/регистрация → создание персонажа → игра; токен в Keychain (iOS) и в хранилище приложения (Android); тексты ошибок общие, из `shared`;
- CI: серверные тесты на PostgreSQL, сборка Docker-образа сервера и его запуск; после деплоя — смоук-тест живого сервера (`.github/workflows/engine-smoke.yml`).

API: `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/me`, `POST /api/characters`, `GET /api/game`, `POST /api/game/move`, а также `GET /api/locations/{id}`, `GET /api/content/report`, `GET /api/health`.

**Этап 0 — каркас**

- Сервер загружает весь мир из `content/` (≈1400 локаций, 765 предметов, 305 NPC, 122 диалога) и отдаёт `GET /api/locations/{id}`, `GET /api/content/report`, `GET /api/health`.
- Оба приложения показывают локацию (название, описание, кто здесь) и позволяют ходить по выходам — с общей логикой экрана из `shared`.
- CI (`.github/workflows/engine.yml`): на Linux — тесты сервера на реальных данных, тесты общего модуля, сборка APK (артефакт `android-debug-apk`); на macOS — тесты общего модуля под iOS, XCFramework и сборка приложения для симулятора. Отчёт о проблемах контента выводится аннотацией.

```sh
cd engine

./gradlew :androidApp:installDebug                                            # приложение ходит на сервер Railway
./gradlew :androidApp:installDebug -Ptz.serverUrl=http://10.0.2.2:8080        # …или на локальный сервер из эмулятора
./gradlew :shared:assembleSharedDebugXCFramework && (cd iosApp && xcodegen && open Tz.xcodeproj)   # iOS, нужен macOS
```

## Архитектура дальше

- **Протокол.** Сервер отдаёт «вид» экрана (локация, персонаж, инвентарь, диалог, журнал боя) и принимает действия (`move`, `attack`, `say`, `use`, `buy`…). REST для запросов и WebSocket для событий в реальном времени (чат, удары, приход NPC). Все типы — в `shared`, так что сервер и приложения не могут разойтись.
- **Состояние мира.** PostgreSQL: игроки, персонажи (с идентификатором мира — решение «один мир», README «Миры»), инвентарь, банк, кланы — таблицы с явными полями вместо строк `a|b|c`. Живое состояние локаций (NPC, лежащие предметы, таймеры) — в памяти сервера с периодическим сохранением; мир «идёт» по серверному таймеру, а не только когда рядом игрок.
- **Правила.** Чистые функции без ввода-вывода (`calcparam`, попадание, урон, каст, регенерация, опыт, цены), случайность — через передаваемый генератор. Паритетные тесты: те же входы прогоняются через старый PHP (`game/1`) и через Kotlin, результаты сравниваются.
- **Квесты и диалоги.** Вместо 286 вставок `eval:` — декларативные условия и действия («есть предмет», «забрать», «выдать», «кулдаун на игроке», «телепорт», «обучить»). Сервер пускает только в темы, которые игрок видел.
- **Безопасность с нуля.** Токены сессий (не пароль в ссылках), пароли через Argon2/bcrypt, роли вместо «админ по логину», каждое действие проверяется на сервере.
