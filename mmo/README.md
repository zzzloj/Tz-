# MMO-клиент и сервер на Open MMORPG (MMORPG KIT)

Решение владельца 07.10: живой мир на открытом фреймворке MMORPG KIT в сборке сообщества
[Open MMORPG](https://github.com/open-mmorpg/OpenMMORPG) (MIT). На него переносятся наши правила
(формулы боя, мощь, баланс), предметы, монстры и места, а графика — модели по нашим картинкам.

## Устройство
- `Assets/OpenMMORPG` — сам фреймворк, git-подмодуль на конкретный коммит. Свой код фреймворка не правим:
  наше лежит в `Assets/Tz` (наследники, partial-классы, аддоны).
- Unity 6000.0.58f2, как у нынешнего клиента: лицензия Personal из CI (Unity_lic.ulf) у 6000.3 не проходит («com.unity.editor.headless was not found»). Фреймворк заявлен под 6000.3+, совместимость проверяет сборка. Пакеты — `Packages/manifest.json` по списку фреймворка.
- `ProjectSettings` — базовые настройки из фреймворка (`Tools~/ProjectSettings`).
- Сборка: `.github/workflows/mmo.yml`, метод `MmoBuild.BuildServer` (Linux, запускается без графики, роли — ключами командной строки) и `MmoBuild.BuildAndroid`.

## Шаги
1. Пустой проект с фреймворком собирается в CI под Linux-сервер и Android. ← сейчас
2. Стартовые сцены: инициализация, вход, выбор героя, карта порта; сервер с Postgres на VPS.
3. Наши формулы (`GameplayRule`), импорт предметов и монстров стартовой зоны из `content/`.
4. Мобильное управление, 3D-модели по нашим картинкам.
