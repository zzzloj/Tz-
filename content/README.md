# Контент мира

Здесь лежат данные игры в UTF-8 JSON: предметы, заклинания, приёмы, NPC, диалоги и локации. Это единственный источник: файлы, которые читает движок (`game/1/items`, `npc`, `speak`, `desc`, `l_f`, `l_i`, `l_t`, cp1251), собираются из этого каталога при сборке образа и в тестах.

```sh
python3 tools/content/build.py content <каталог game/1>   # JSON → файлы движка
sh tests/content.sh                                       # проверка: собрать и выгрузить обратно
```

Значения полей описаны в `docs/data-fields.md`, квесты и их логика — в `docs/quests.md`, имена полей заданы в `tools/content/schema.json`.

## Каталоги

| Каталог | Что внутри | Файл движка |
|---|---|---|
| `items/<id>.json` | предметы `i.*`, заклинания `m.*`, приёмы `p.*` | `items/<id>` |
| `items_dublon/<id>.json` | цены в дублонах для второго магазина | `items1/<id>` |
| `npcs/<id>.json` | шаблоны NPC | `npc/<id>` |
| `dialogs/<id>.json` | диалоги NPC | `speak/<id>` |
| `locations/<id>.json` | локация: название, зона, выходы, описание, таймеры, стартовые объекты | `l_i/<id>`, `l_t/<id>`, `l_f/<id>` |
| `balance/*.json` | новый баланс (04.10.2026) поверх старых полей: монстры и NPC (`npcs.json`), вещи, еда, самоцветы (`items.json`), комплекты (`sets.json`). Собирается скриптом `tools/balance/run.py`, руками не править. Старый стенд их не читает | — |
| `raw/<каталог>/<файл>` | файлы, которые не являются чистыми данными: PHP с логикой (3 NPC со случайными именами, 6 диалогов с логикой замков, 3 файла кода в `items/`), тексты справки `desc/`, шутки `speak/h.*`. Лежат как есть, только в UTF-8 | тот же путь |

## Как устроены записи

Строки движка вида `имя|цена|…` разобраны на именованные поля. Число записано числом, `a:b:c` — списком, всё остальное — строкой. Если значение не укладывается в ожидаемый тип, оно остаётся строкой как было. Лишние части строки лежат в `extra`. Пустые поля сохранены (`""`), потому что движок различает их количество.

```json
{"id": "i.w.r.b.air", "kind": "weapon", "name": "лук воздуха", "price": 600,
 "dmg_min": 1, "dmg_max": 10, "req": [3, 3], "speed": 5, "verb": "из лука воздуха", "ammo": ""}
```

- **NPC.** `char` и `war` разобраны по полям. `items`, `osvej` — список `{id, count}`. `equip` — список id, `itemsrnd` — `{id, chance, min, max}`. Остальные ключи (`bank`, `owner`, …) лежат как в движке. `{"$php": …}` обозначает значение, которое в движке было не строкой.
- **Диалог.** Тема — строка либо `{text, options: [{label, goto}]}`. `{{sid}}` подставляется как `$sid` (ссылка с сессией игрока). Строки с префиксом `eval:` — PHP-код внутри данных, движок его выполняет.
- **Локация.** `exits` — `[{label, target}]`, `zone` — 0 обычная, 1 охраняемая, 2 цитадель тамплиеров, 3 форт пиратов. `timers` и `objects` — стартовое состояние мира из архива: ключ таймера — время срабатывания, объекты — NPC (как шаблоны) и предметы (`имя|кол-во|истекает`).

## Правила

- Правки делаются здесь, а не в собранных файлах. `tests/content.sh` (он же в CI) проверяет, что контент собирается и выгружается обратно без изменений.
- Изменения, которые меняют экраны игры, требуют `[ab-accept]` в сообщении коммита (см. `tests/README.md`).
- Символы вне cp1251 (эмодзи, «№» можно, `€` можно, `ł` нельзя) сборка отклонит: движок работает в cp1251.

## Откуда взялось

Выгружено один раз из архива `tools/content/export.php` 28.09.2026. Проверки:
- `tools/content/verify.php` — все 3816 файлов после сборки совпадают с исходными: побайтно, а PHP-массивы и сериализованные локации через `===`;
- дифференциальный тест игры на исходных и собранных файлах — 3 × 513 одинаковых экранов.

Отличия от архива:
- **Нет записей 36 игроков 2007 года** (в `l_i` лежали их персонажи с паролями и IP). Экспортёр пропускает `u.*`. Для сравнения с оригиналом их можно выгрузить локально с `TZ_EXPORT_PLAYERS=1`.
- `l_t/` (запасная копия локации, которую движок читает, только если `l_i/` не разобрался) теперь совпадает со стартовым `l_i/`. В архиве это были устаревшие копии, 119 из них пустые.
- 99 локаций с неверными длинами строк в `serialize` записаны правильно. Движок и раньше чинил их при загрузке.
- Перевод строки в конце файлов предметов убран: движок и так обрезал его при разборе.
- Латинские буквы-двойники в кириллических словах («Aнтoниo», «кулaкaми»; ими экономили WAP-трафик) заменены на кириллицу — 1174 слова, одновременно в контенте и в строках кода (`tools/content/normalize_lookalikes.php`). Нарочные случаи оставлены: регулярки фильтра мата и шутка «Chupa Chups». Дифференциальный тест с `AB_FOLD=1` (двойники сворачиваются перед сравнением) — 3 × 513 одинаковых экранов.
