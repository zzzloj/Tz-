# Unity-клиент (прототип)

Решение владельца 06.10: больше графики, меньше текста. Это новое приложение к тому же серверу, сервер не меняется (`https://217-177-74-66.sslip.io`, тот же REST и WebSocket, что у Android и iOS). Нынешние приложения остаются, пока Unity-версия их не догонит.

## Что в прототипе
- **Вход** и создание персонажа.
- **Место — сцена.** Картина места на фоне, монстры и NPC стоят на ней фигурами. Над каждым имя и уровень, полоска здоровья, кружок с вашим шансом (цветом) и отсчёт его удара по вам. Тап по фигуре — удар.
- **Бой:**
  - урон вылетает цифрами, фигура вздрагивает и вспыхивает;
  - когда бьют вас, краснеет экран;
  - убитые тают;
  - опыт и новый уровень всплывают надписями.
- **Экран лежит горизонтально**, как на образце владельца (07.10). Картина места занимает весь экран. Слева вверху герой: полоска здоровья, имя, уровень и мощь, опыт идёт полоской по левому краю. Справа вверху миникарта, под ней кнопка «Герой».
- **Ходьба** — джойстик слева внизу (`Movement.cs`):
  - метки по кругу светятся там, где есть выход;
  - тянете ручку к выходу — над джойстиком пишется, куда он ведёт, отпускаете — идёте;
  - если держать, герой идёт дальше в ту же сторону, место за местом, пока не начнётся бой;
  - сторону выхода клиент берёт из его названия («на север в рощу»), а если в названии её нет, то из координат на карте;
  - выходы без стороны («в дом», «наверх») — кнопки над джойстиком.
- **Миникарта** показывает улицы вокруг точками. Вы — золотой кружок, места, куда можно пройти, подсвечены, тап по такому — идти туда.
- **На земле** лежат иконки вещей и трупов. Тап по вещи — взять, по трупу — забрать всё.
- **Внизу** две-три строки журнала, они гаснут сами.
- **«Герой»:** кукла с вещами по слотам, рюкзак сеткой. Тап по слоту снимает вещь, тап в рюкзаке надевает.
- **Пока в обычном приложении:** разговоры, торговля, банк, ремёсла, заклинания и приёмы, кланы, форум, почта.

Фигуры пока делаются из квадратных портретов с мягким круглым краем. Нарисованные фигуры в полный рост кладутся в `content/art/figures/<ключ>.png` и подменяют их (промпты — `PROMPTS.md`).

## Устройство
- Сцена пустая. `Boot` (`Assets/Scripts/Runtime/App.cs`) создаёт камеру, холст и экраны из кода, вручную в редакторе ничего не раскладывается.
- `Api.cs` — обращения к серверу. `Models.cs` — нужная часть протокола. `UI.cs` — палитра, шрифты, картинки, кнопки, полоски, эффекты. `GameScreen.cs` — сцена и бой. `Movement.cs` — джойстик и миникарта. `Paperdoll.cs` — герой.
- `tools/prepare.py` перед сборкой копирует картинки из `content/art` (webp → png/jpg) и шрифты в `Assets/Resources`. В репозиторий они не кладутся.
- `Assets/Scripts/Editor/BuildScript.cs` (`BuildScript.BuildAndroid`) создаёт сцену, выставляет настройки Android и собирает APK в `build/Android/`.

## Сборка
- CI: `.github/workflows/unity.yml`. При каждом изменении C# проверяется на заглушках Unity (`dotnet build unity/tools/check`). Если заданы секреты лицензии Unity (`UNITY_EMAIL`, `UNITY_PASSWORD`, `UNITY_LICENSE`), GameCI собирает APK. Он лежит в артефактах запуска как `amulet-unity-apk`.
- Лицензия для CI (`UNITY_LICENSE`): содержимое `/Library/Application Support/Unity/Unity_lic.ulf` на Mac (папка в корне диска, не в домашней). Файл появляется после активации Personal в Unity Hub.
- Локально: Unity 6000.0.58f2. Сначала `python3 unity/tools/prepare.py`, потом открыть папку `unity` в Unity Hub.
