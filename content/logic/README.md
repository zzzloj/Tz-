# Логика диалогов и квестов для нового движка

Здесь лежит то, что в старой игре было PHP-кодом внутри диалогов (`eval:` в `content/dialogs/*.json` и PHP-файлы `content/raw/speak/n.*`). Новый движок (`engine/`) PHP не выполняет: для каждой такой темы здесь записаны условия и действия в JSON. Старый движок эти файлы не читает, его диалоги не меняются.

- `<npc>.json` — логика тем одного диалога (имя файла = id диалога, как в `content/dialogs/`).
- `timers.json` — все задержки квестов в одном месте: сколько ждать и общая ли задержка для всех игроков.

Сервер при загрузке проверяет файлы (неизвестные условия и действия, предметы, таймеры, темы) и показывает проблемы в `GET /api/content/report`; тест `LogicTest` падает, если проблемы есть. Там же список тем с `eval:`, для которых логики ещё нет (`untranslated`): игрок видит в них «Этот разговор пока не перенесён».

## Файл диалога

```json
{
  "id": "n.Arant",
  "topics": {
    "qvok": [
      {
        "if": [{"has": "i.q.instrum"}],
        "do": [{"take": "i.q.instrum"}, {"give": "i.arrow", "count": 12}, {"give": "i.w.r.b.short"}, {"exp": 10}],
        "text": "Спасибо, <imja>, мне они как раз нужны..."
      },
      {"text": "У тебя нет инструментов!"}
    ]
  }
}
```

Тема — список правил. Сервер берёт **первое правило, все условия `if` которого выполнены** (нет `if` — выполнено всегда), выполняет его действия `do` и показывает `text`. Если ни одно правило не подошло, показывается пустой текст с вариантами темы.

Поля правила:

| Поле | Что делает |
|---|---|
| `if` | список условий, все должны выполняться |
| `do` | список действий по порядку |
| `text` | реплика NPC; если не задана, берётся текст темы из `content/dialogs` (когда он не `eval:`). `<imja>` — имя игрока, `{left:<таймер>}` — сколько минут осталось до конца таймера (с округлением вверх), `{arg}` — выбранный аргумент варианта |
| `options` | варианты ответа вместо вариантов темы из `content/dialogs`: `[{"label": "…", "goto": "тема", "arg": "…", "if": [условия]}]`; `arg` и `if` необязательны, вариант с `if` показывается, только если условия выполнены (так переносятся `eval:` в метках вариантов, которые выбирают текст и `$id`) |
| `hide` | id тем, варианты на которые убрать из списка (например, «Возьми задание», если оно уже выполнено) |
| `goto` | после действий показать другую тему этого же диалога (её правила тоже выполнятся); `text` этого правила, если есть, ставится перед текстом той темы |

Варианты темы (из `content/dialogs`) остаются, если правило не задаёт `options`. Тема может быть только здесь, без записи в `content/dialogs` (так переносятся PHP-диалоги из `raw/speak`).

## Условия

| Условие | Выполнено, если |
|---|---|
| `{"has": "i.x", "count": 3}` | у игрока в рюкзаке не меньше `count` (по умолчанию 1) предметов с точно таким id |
| `{"lacks": "i.x", "count": 1}` | меньше `count` (по умолчанию 1), то есть предмета нет |
| `{"money": 100}` | монет (`i.money`) не меньше 100 |
| `{"equipped": "i.a.h."}` | надет предмет, id которого начинается с этой строки |
| `{"skill": "smith", "min": 4, "max": 5}` | навык (ключи — `Rules.SKILLS`: `str dex int hand coldweapon … weaver`, а также `exp`, `points`) в пределах; `min`/`max` необязательны |
| `{"newbie": true}` | сумма атрибутов, навыков и свободных очков равна 5 (новый персонаж, как `war[13]==5` в старом коде); `false` — наоборот |
| `{"ready": "n.X.qv"}` | таймер не идёт (истёк или не запускался) |
| `{"waiting": "n.X.qv"}` | таймер идёт |
| `{"flag": "ключ"}`, `{"flag": "ключ", "value": "x"}` | у игрока есть флаг (и он равен `value`) |
| `{"noflag": "ключ"}` | флага нет (или истёк) |
| `{"flag": "ключ", "world": true}`, `{"noflag": …, "world": true}` | то же для флага всего мира (одно состояние на всех игроков: «ожерелье уже подброшено») |
| `{"known": "m.x"}`, `{"unknown": "m.x"}` | заклинание или приём выучены / не выучены |
| `{"here": "i.x"}`, `{"notHere": "i.x"}` | предмет (в том числе неподвижный `i.s.*`) лежит / не лежит в этой локации |
| `{"npcAt": "n.X", "location": "x1x2"}` | NPC с таким ключом стоит в локации (без `location` — в текущей) |
| `{"noNpcAt": "n.X", "location": "x1x2"}` | не стоит |
| `{"arg": ["1", "5"]}` | игрок выбрал вариант с одним из этих `arg` |
| `{"chance": 30}` | случайно, с вероятностью 30 % |
| `{"sex": "f"}` | пол персонажа |
| `{"ghost": true}` | персонаж призрак (`false` — жив) |
| `{"any": [условия]}` | выполнено хотя бы одно |
| `{"not": условие}` | условие не выполнено |

## Действия

| Действие | Что делает |
|---|---|
| `{"take": "i.x", "count": 2}` | забрать предметы. Если их не хватает, **ничего из `do` не выполняется**, игрок видит «У вас нет: …» (в старом коде нехватка часто молча игнорировалась, а награда выдавалась — это ошибка, её не переносим) |
| `{"give": "i.x", "count": 2}` | выдать предметы (`count` по умолчанию 1) |
| `{"exp": 25}` | опыт, как `addexp()`: сверх порога — очко опыта |
| `{"start": "n.X.qv"}` | запустить таймер из `timers.json` |
| `{"stop": "n.X.qv"}` | сбросить таймер |
| `{"set": "ключ", "value": "x", "for": 3600}` | поставить флаг игроку; `value` по умолчанию `"1"`, `for` — через сколько секунд флаг исчезнет (без него — навсегда) |
| `{"clear": "ключ"}` | убрать флаг |
| `"world": true` в `set`/`clear` | флаг всего мира, а не игрока |
| `{"giveNpc": "i.x", "npc": "n.X", "location": "x1x2", "count": 1}` | дать NPC предмет: он окажется в его трупе (подбросить вору украденное) |
| `{"learn": "m.x"}` | выучить заклинание или приём (без проверок и оплаты; учитель с проверками — `teach`) |
| `{"teach": "coldweapon", "cost": 180, "min": 0, "max": 4}` | учитель, как тема `skill|coldweapon|180|0|4` (`f_speakskillup.dat`): очко опыта, пределы, выбор, что понизить, бесплатно для новичка; для `m.*`/`p.*` — изучение за деньги. Текст ответа формирует сервер |
| `{"teleport": "x1x2"}` | перенести игрока в локацию |
| `{"spawn": "n.template", "location": "x1x2", "key": "n.template.q1"}` | поставить NPC из шаблона (`location` по умолчанию текущая, `key` — ключ экземпляра, по умолчанию как шаблон); если NPC с таким ключом там уже есть, ничего не делает |
| `{"remove": "n.X", "location": "x1x2"}` | убрать NPC |
| `{"place": "i.x", "count": 1, "location": "x1x2"}` | положить предмет на землю (исчезнет через 10 минут, как брошенный) |
| `{"removeHere": "i.x"}` | убрать предмет с земли в текущей локации |
| `{"resurrect": true}` | воскресить призрака (с 0 HP, как у камня) |
| `{"heal": 20}`, `{"heal": "full"}` | вылечить |
| `{"say": "h.fomenko"}` | добавить к тексту случайную строку из `content/raw/speak/h.*` (шутки) |
| `{"journal": "текст"}` | строка в журнал игрока |
| `{"handler": "имя"}` | особая логика, которая пишется в коде сервера (арена, кости, свадьба, замки); пока обработчика нет, тема считается непереведённой |

## Таймеры (`timers.json`)

```json
{
  "n.Ditrih.qv": {"scope": "world", "min": 18000, "max": 36000, "about": "Дитрих набирает рекрутов"},
  "n.Goston.spec": {"scope": "player", "min": 18000, "max": 36000, "about": "янтарь для Гостона"}
}
```

- `scope: "world"` — один таймер на весь мир (масштабные квесты: пока идёт, задание не получит никто, как в оригинале); `"player"` — у каждого игрока свой (мелкие задания и обмены).
- `min`/`max` — длительность в секундах, берётся случайная между ними.
- `about` — для людей: что это за задержка. Все задержки игры собраны в этом файле, чтобы их было удобно менять по результатам игры.

Имя таймера — `<диалог>.<ключ из старого кода>` (`qv`, `qv1`, `spec`, …), чтобы по нему находился старый код.
